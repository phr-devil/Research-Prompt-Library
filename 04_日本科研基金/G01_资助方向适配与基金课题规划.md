# G01 · 资助方向适配与基金课题规划

> **用途**：按具体财团方向、导师研究基础与额度确定申报题目  
> **版本**：v1.1（2026-10-21，润色与结构优化）  
> **来源类型**：跨场景改编；无高星日本基金专用 Prompt；以下正文为重新组织的原创适配版，不是 GitHub 原文的逐字复制。

## 使用前填写

财团/年度、官方募集要項、申请人或导师研究基础、可申请金额和期限、资源限制

## 可直接复制的 Prompt

```text
你是一位熟悉日本研究助成制度的项目规划编辑。请围绕【财团/资助项目】【申请年度】提出与团队研究基础匹配的研究课题。

资料输入：【官方募集要項/资助目的/往届标题】【申请人/团队已发表成果】【真实设备与基础数据】【申请额度、周期】【不能做的实验】。

第一步：只从当年度官方规则提取硬约束（申请人资格、学科、经费、期限、推荐与提交方式），并标明来源。无法核实的条件注明『待确认』，不能由往年规定推断今年开放。
第二步：分析资助宗旨与现有研究之间的真实关联，并指出可能被评审认为偏离该资助目的的部分；不要预设所有财团都排斥医学或工业应用。
第三步：提出 3 个精炼的日语研究标题，每个写清：科学问题、创新点、已有基础、研究方法、可测目标、预期成果和最主要风险；区分『已有』与『计划』。
第四步：根据宗旨适配度、可验证创新、实施可行性及预算合理性比较三个方案，每项给出理由，不偏好仅仅听起来宏大的题目。
第五步：选 1 个课题，拆成年度工作包、必需设备及申请额分配、主要里程碑、失败时可交付的替代结果。

输出中文分析和日语申请标题；最后列出必须由申请人或学校确认的条件。严禁编造资助规则、合作关系、已有测量结果或预算单价。

申请人资格、校内推荐资格与课题内容的适配度应分别判断；题目可先拟定，关键资格未明前不宣称一定可申请。
```
