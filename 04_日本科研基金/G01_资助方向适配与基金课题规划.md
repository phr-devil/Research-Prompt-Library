# G01 · 资助方向适配与基金课题规划

> **用途**：按具体财团方向、导师研究基础与额度确定申报题目  
> **版本**：v1.4（2026-10-26，使用体验与任务边界精修）  
> **来源类型**：跨场景改编；无高星日本基金专用 Prompt；以下正文为重新组织的原创适配版，不是 GitHub 原文的逐字复制。

## 使用前填写

基金全名和年度、最新募集要項、真实研究基础、资助期限和额度、当前选题（如已有）、模式（新选题/优化现有）

## 可直接复制的 Prompt

```text
任务：为【日本资助项目与年度】评估并规划可申报课题。模式：【从零选题 / 优化已确定题目】。依据【当年度募集要項】【申请人和团队真实成果】【资源/期限/申请额度】【不可实施的事项】进行判断。

先区分：①申请人个人资格；②学校推荐和提交程序；③研究方向与资助宗旨的匹配。必须使用当年度官方证据，缺少材料时标记待确认，不把历史规则当现行规则。如确定不符合硬性条件，优先说明并停止撰写不适格申请书；仅在用户要求时提出替代方向。

若为“从零选题”：提出最多 3 个自然简洁的日语题名。每个给出科学问题、最接近研究的具体差别、已具备证据、可实现方法、评价指标与主要风险。
若为“优化已确定题目”：尊重已有范围与被否决的旧方向，默认不另起三个新题。直接指出题目、研究目标、工作内容与财团宗旨的偏差，并提供最小必要修改。
检查可执行性：课题周期、实验任务、设备/材料需求、预算分类与可交付结果是否一致；一年的资助不强行设计三年计划。预算单价或前期数据未知时不得虚构。

输出：①资格和宗旨适配判断（符合/不符/待确认，附证据）②所选模式的题目或修订稿③可执行里程碑及最主要风险④仅列必要的待确认问题。中文解释、日语题目；不自动生成整份申请书。
```
