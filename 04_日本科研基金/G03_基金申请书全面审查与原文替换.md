# G03 · 基金申请书全面审查与原文替换

> **用途**：提交前检查逻辑/真实性/日语/Word-Excel一致性，给出精确替换文本  
> **版本**：v1.3（2026-10-26，定向质量修订）  
> **来源类型**：跨场景改编；无高星日本基金专用 Prompt；以下正文为重新组织的原创适配版，不是 GitHub 原文的逐字复制。

## 使用前填写

最新版 Word/Excel 等申请文件、对应募集要項、版本顺序与重点核查问题

## 可直接复制的 Prompt

```text
请以日本研究助成提交前审核员和日语编辑的视角，核对实际可读取的【最终版本申请文件】和【当年度官方募集要項】；必须先列明已读文件及未读取范围。

先列可实际读取的文件及版本、当年度规则的正式发布时间和更新通知；官网、募集要項、FAQ 冲突时列出具体条款、适用年度和优先级依据，不能自行选有利版本。

按四层检查：
A 形式合规：年度、项目名称、表格版本、字数、附件、签章、金额、时间、提交方法。
B 科学与逻辑：研究目标和方法是否能相互证明；研究基础是否真实；结果指标是否可测；预算与年度工作包是否一一对应。
C 跨文件一致性：申请者名、导师、课题名、单位、金额分项、年度时间、实验材料、引用文献是否一致。
D 日语表达：语义歧义、冗余、敬语不合适、中文翻译腔、重复的『本研究では』、不自然的书面表达；不为追求文采改动科学事实。

每个问题按『阻断提交（有当年度官方条款证据） / 重要修正（有事实或跨文件依据） / 语言优化（建议，可保留原文）』标注，给出【文件与定位（栏目/页/单元格）｜逐字原文｜可直接替换全文或具体操作｜依据及风险】。格式或事实问题未必有可替换句，不能强行改写。严禁用『前半段』等无法定位的位置。原文已经正确则不强求修改。

最后只给最优先的 5 项行动、提交材料核对清单，以及仍需学校或财团确认的问题；正确的部分不为凑数而修改。若文件没有成功读取，必须明确说明无法核查的范围，不得猜测里面的内容。

对照的是当年度官方条款，不得自行断言附件必须邮寄或提交论文原文；规则不明时明确写『待核实』。

核验界限：对预算合计、单元格公式、字数和附件完整性，只有实际读取并计算/比较时才能标记 PASS；未读单元格、缺失附件、无法确认排版或签章时写 UNKNOWN。优先指出真实阻断项，不把日语措辞偏好升级为“违反规定”。
```
