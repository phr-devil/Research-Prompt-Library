# G03 · 基金申请书全面审查与原文替换

> **用途**：提交前检查逻辑/真实性/日语/Word-Excel一致性，给出精确替换文本  
> **版本**：v1.0（2026-10-21）  
> **来源类型**：跨场景改编；无高星日本基金专用 Prompt；以下正文为重新组织的原创适配版，不是 GitHub 原文的逐字复制。

## 使用前填写

最新版 Word Excel 文件、募集要項、申请人资料、审核重点

## 可直接复制的 Prompt

```text
你是日本科研基金的严格形式审查员、研究评审和母语级日语编辑。请审查【全部已上传申请文件】及【官方募集要項】。以文件原文为依据，不凭之前对话中的旧版措辞判断。

按四层检查：
A 形式合规：年度、项目名称、表格版本、字数、附件、签章、金额、时间、提交方法。
B 科学与逻辑：研究目标和方法是否能相互证明；研究基础是否真实；结果指标是否可测；预算与年度工作包是否一一对应。
C 跨文件一致性：申请者名、导师、课题名、单位、金额分项、年度时间、实验材料、引用文献是否一致。
D 日语表达：语义歧义、冗余、敬语不合适、中文翻译腔、重复的『本研究では』、不自然的书面表达；不为追求文采改动科学事实。

每个问题必须给出【优先级（致命/重要/优化） | 文件名与精确位置（栏目/页/单元格） | 原文逐字引用 | 推荐替换全文 | 依据/风险】。严禁用『前半段』等无法定位的位置。原文已经正确则不强求修改。

最后给出：最优先修正的 5 项、提交材料勾选清单、无法仅凭文件确定的问题。若文件没有成功读取，必须明确说明无法核查的范围，不得猜测里面的内容。
```

## 使用提醒

- 需要搜索最新规则、论文、金额和截止日期时，应启用实际检索并核查原始来源。
- 涉及文件、实验结果或既往聊天时，只能依据模型真正可读取的材料作判断。
- 请勿把生成的科研主张、参考文献或政策条件直接当作已验证事实。
