# P01 · 论文结构、论证逻辑与图表规划

> **用途**：论文动笔前锁定主线、每幅图和正文段落逻辑  
> **版本**：v1.4（2026-10-26，使用体验与任务边界精修）  
> **来源类型**：融合改写；以下正文为重新组织的原创适配版，不是 GitHub 原文的逐字复制。

## 使用前填写

研究问题、已完成实验和图表、论文核心主张、目标期刊及限制、模式（全文结构/图表结构）

## 可直接复制的 Prompt

```text
任务：基于【研究问题】【当前真实证据】【目标期刊及格式（如已知）】，设计论文论证结构。模式：【全文结构 / 图表结构】。不要为了补齐论文框架而编造实验或结论。

1. 用一句话概括数据真正支持的核心主张；最多提出 3 条有证据支撑的从属贡献。区分新方法、机制证据、应用验证与单纯性能改善。
2. 对每条主张建立「具体主张—已有图表/数据—对照和统计—限制—需补证据」。没有充分证据的主张应删去、降低措辞强度，或明确标记为尚待验证。
3. 若选“全文结构”：按期刊已知要求规划 Abstract、Introduction、Methods、Results、Discussion、Conclusion 的论证任务和段落衔接；不要强制生成未被要求的正文。
4. 若选“图表结构”：逐图说明要回答的科学问题、变量和单位、必需对照、统计表达、主文/补充材料位置；可以建议合并或删除不增加论证价值的图。
5. 最后只指出 3–5 个有实际依据的审稿风险，区分科学设计缺陷、缺失证据和可修复的写作问题；不能凭猜测判定必然拒稿。

输出：先给核心贡献与结论边界，再给所选模式的结构或图表矩阵，最后列最重要的缺口与最小下一步。期刊规范未经实际核查不得假称符合。
```

## 使用提醒

- 只对实际提供或可以核实的材料做判断，缺失资料与权限必须写明。
- 不编造科研数据、基金要求、文献或运行状态。
