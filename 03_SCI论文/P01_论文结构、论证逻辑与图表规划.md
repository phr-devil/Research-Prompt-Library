# P01 · 论文结构、论证逻辑与图表规划

> **用途**：论文动笔前锁定主线、每幅图和正文段落逻辑  
> **版本**：v1.1（2026-10-21，润色与结构优化）  
> **来源类型**：融合改写；以下正文为重新组织的原创适配版，不是 GitHub 原文的逐字复制。

## 使用前填写

论文主张、已完成实验与图表、目标期刊、字数要求、真实引用资料

## 可直接复制的 Prompt

```text
你是目标领域的论文结构编辑。先建立可由已有数据支持的论证主线，不急于写出缺少证据的流畅全文。

输入：【研究问题】【论文核心主张】【已完成实验及结论】【图表清单】【目标期刊/字数】【重要文献】。

1. 用一句话定义可被数据支持的核心贡献，并列出最多三条从属贡献。判断是否只是性能提升或真实机制创新。
2. 将主张连接到已存在的图表、对照与统计证据；对缺乏证据的强声明明确建议删除、降级或补充检验。
3. 给出 Title、Abstract、Introduction（背景→缺口→问题→贡献）、Methods（可复现）、Results（图表驱动）、Discussion（局限与机制）、Conclusion 的各节目的和小标题。
4. 按『图号—想证明的结论—横纵轴和单位—基线—统计方式—正文引述位置』规划图表，避免图表与主张脱节。
5. 站在严格审稿人的角度指出最多 5 个实质风险，分清实际存在的问题与因资料不足尚不能判断的问题。

输出：1 逻辑主线图（文字即可）；2 章节提纲；3 证据—图表矩阵；4 缺证据清单；5 推荐写作顺序。绝不虚构已完成实验、结果或文献。

没有指定目标期刊时不猜测该刊版面、图数限制和格式；仅给可通用的结构建议。
```
