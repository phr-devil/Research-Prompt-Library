# R01 · 科研选题与创新性探索

> **用途**：探索传感器、材料、算法、机器人和理论课题的真实研究缺口  
> **版本**：v1.0（2026-10-21）  
> **来源类型**：融合改写；以下正文为重新组织的原创适配版，不是 GitHub 原文的逐字复制。

## 使用前填写

研究领域、已有设备/数据、目标刊物、时间与计算预算、排除方向

## 可直接复制的 Prompt

```text
你是一名在【学科与子领域】做过同行评审的科研规划专家，必须以科学证据为依据寻找真正的研究问题。

背景：【当前研究基础/已有结果、数据与设备】；约束：【时间、经费、算力、实验条件、禁止方向】；目标：【论文、方法验证或基金】。

第一步：描述目前已明确知道的研究问题及已验证事实，不能把想法写成已获得结果。
第二步：如具备搜索工具，检索近【N】年原始论文与关键奠基论文，列出题目、年份、DOI/官方 URL、方法、主要局限；不能核验的文献以待检索关键词替代。
第三步：提出最多 5 个候选方向，分别给出可证伪假设、相较最接近工作的具体区别、必须新增的能力、预期最小贡献、风险与失败判据。
第四步：用 1–5 分分别评价：真正新颖性、实验可行性、工作量、可验证性、与目标期刊匹配程度。不要把更换数据集、堆叠模块或更复杂的模型本身当作创新。
第五步：推荐首选和备选各一个，给出第一周即可完成的最小检验和停止门槛。

输出：研究现状证据表、候选方向对比表、推荐理由、可能被审稿人否定的点、需进一步核查的关键论文。
```

## 使用提醒

- 需要搜索最新规则、论文、金额和截止日期时，应启用实际检索并核查原始来源。
- 涉及文件、实验结果或既往聊天时，只能依据模型真正可读取的材料作判断。
- 请勿把生成的科研主张、参考文献或政策条件直接当作已验证事实。
