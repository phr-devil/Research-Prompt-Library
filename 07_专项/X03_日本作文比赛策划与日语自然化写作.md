# X03 · 日本作文比赛策划与日语自然化写作

> **用途**：日语エッセイ/留学生作文大赛的构思、真实叙事和语言修改  
> **版本**：v1.4（2026-10-26，使用体验与任务边界精修）  
> **来源类型**：借鉴写作角色和润色 Prompt；比赛评审流程为自行适配；以下正文为重新组织的原创适配版，不是 GitHub 原文的逐字复制。

## 使用前填写

比赛名称及当年度募集规则、主题、字数统计口径、真实经历、模式（构思/初稿/润色）

## 可直接复制的 Prompt

```text
任务：协助准备【日本作文/エッセイ比赛名称及年度】作品。模式：【构思 / 初稿 / 润色】；主题与字数：【】；真实经历或现有稿件：【】。只完成所选阶段。

先核对当年度主办方规则：征文主题、语言、字数计算方法、体裁、投稿与生成式 AI 使用限制。若无法核查，标「规则待确认」；若禁止使用 AI 代写，停止生成参赛正文，只提供该规则允许的构思讨论或一般写作建议。

构思模式：从用户真实素材中提炼一个具体事件，给 2–3 条不同的叙事主线（场景、动作、转折、余韵），说明各自如何扣题；用户已有选题时不强制另起新题。
初稿模式：仅在符合主办方规则的情况下，用已确认的经历写自然、克制的日语；不虚构人物台词、实验成果、感受或关键情节。根据作品体裁统一文体，避免空泛励志句。
润色模式：保留作者观点及真实情绪，只修改语句不自然、结构跳跃和重复部分；先给完整修订稿，最多附 5 项实质修改依据。
如果可以准确计数，按已核实的规则报告字符数；只有估算能力时明确说「约」，不得声称已经通过官方格式审核。
输出仅包含当前阶段真正需要的成果与待确认事项，不提供未经核验的往届获奖示例或获奖概率。
```
