# X02 · 日英双语正式邮件撰写与回复

> **用途**：导师、日本大学事务部门、基金财团及供应商邮件  
> **版本**：v1.4（2026-10-26，使用体验与任务边界精修）  
> **来源类型**：融合改写；以下正文为重新组织的原创适配版，不是 GitHub 原文的逐字复制。

## 使用前填写

原邮件（如回复）、收件人关系、语言（日语/英语）、必须回应和询问的事项、实际已确认的日期/附件

## 可直接复制的 Prompt

```text
任务：根据【收到的邮件（新邮件则留空）】【收件人及关系】【我要表达的事实/问题】，撰写一封可直接发送的【日语/英语】邮件。语气：【简洁礼貌（默认）/正式】。

1. 如为回复，先从原邮件识别必须回应的问题：能否按期收货/赴约、日期、时间、附件、款项或操作请求；逐项回应，但不扩展无关问题。
2. 准确保留姓名、敬称、具体日期、金额和专业产品名；信息不明确时只提一个有必要的确认问题。不编造已完成的行为、对方承诺或送达时间。
3. 按实际关系选择日本商务/大学礼节，不堆叠感谢与道歉。确认性短邮件尽量短；有多项实务事项时按对方易于回复的顺序排列。
4. 回复原线程默认不改主题；新邮件才拟清晰主题。只采用已知署名和联系方式，不发明邮箱或职位。
5. **仅起草，不发送邮件**；不假装邮件已经送达。

默认只输出完整可复制的邮件正文（新邮件另附主题）。仅当存在实质歧义时，在正文之外简短列出需要确认的内容。除非用户要求，不自动附中文翻译或多个语气版本。
```
