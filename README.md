# Research Prompt Library v1.4.1 · 个人科研工作提示词库

> 创建：2026-10-21｜最近修订：2026-10-26（v1.4.1）｜格式：Markdown 纯文本｜**14 条核心 + 3 条专项**。所有 Prompt 可以单独复制到 ChatGPT、Claude 或其他通用大模型；不依赖插件、Agent、Skill 或软件部署。

## 使用方法

1. 根据下表选择最接近的任务，每个具体步骤优先选一条 Prompt；跨阶段任务可顺序使用，如 S01 发现候选 → S02 核查资格 → G02 撰写申请书。
2. 打开文件，复制 **「可直接复制的 Prompt」** 代码块。只填写与你本次任务有关的【参数】，已有资料可直接粘贴或上传，不必复制整页说明。
3. 涉及外部事实，请给模型开启联网搜索并要求官方证据；涉及你的文件，确保文件实际上传且可读取。
4. 多轮协作时，保留研究背景与最终版本，尽量不要重复添加互相冲突的长指令。
5. 如果一个 Prompt 三次使用后仍不理想，再对其迭代并在文件开头更新版本；不用为了小变体复制十份。

## 来源透明度

本项目只参考 **公开 GitHub 仓库中的普通文字 Prompt**，不安装或嵌入第三方 Skill/Agent。Fabric 虽然有软件实现，这里仅参考其公开 `data/patterns/*/system.md` 纯文本提示词。

**重要区别**：这些并不是从 GitHub 原文一字不变搬来的 17 份模板。具体实践中不存在每个任务都有一份成熟高星 Prompt，因此采用“阅读原文 → 提炼任务组织逻辑 → 针对科研场景重写”的方式。每个文件底部给出匹配的 Prompt 页面及改编性质。尤其是日本基金的三项、科研对话高保真接力、Codex审计、日语作文比赛，均属于**跨场景原创改写**，不能误以为 GitHub 有成熟的高星同名模板。

如果你只需要最优先六条：`S01`、`G02`、`G03`、`P03`、`L01`、`M01`。

## 不要继续拆分的项目

- 四个翻译方向合并为 `L01`，使用参数指定语言和文体。
- IMRaD 各章节合并为 `P02`，使用 `Section` 参数。
- 搜索基金、奖项、会议、设备资助合并为 `S01`。
- 日英写作润色与消除机械表达合并为 `L02`；科学内容独立由 `P03` 和 `G03` 审查。
- 基金的每个栏目不新建文件，在 `G02` 中依据官方表格逐栏处理。

## 质量底线

- 对文献、截止日期和资助规则，必须使用原始来源核实，不能编造引用。
- 对缺失文件、未运行实验和读不到的聊天，不得声称已经查阅。
- 统计结果必须保留样本量、单位、区间、随机种子和验证状态；模拟不等于实测。
- 文字自然化是修辞改进，不是规避 AI 检测或绕过机构的 AI 使用规则。
- 各开源来源的许可证不同，本库是针对个人场景撰写的新提示词；如未来公开二次发布 GitHub 原文，应逐个检查原仓库授权和署名条款。

详见 [SOURCES.md](SOURCES.md)（来源列表与热度快照）和 [00_使用规范.md](00_使用规范.md)。

## v1.3 定向质量修订（2026-10-26）

**不增加目录、文件或 Prompt。** 本轮只修订 X01、R02、M01、G02、G03、R01、P02、P03、S02、S01、L01、M02，以及已有 README、SOURCES 和通用规范。未提及的 Prompt 保留原文件版本。

- **工程执行门禁**：区分只读审计、批准的代码修复、低成本验证和必须另行批准的 GPU/正式实验；严禁伪造签名、人工批准和 PASS 记录（X01、R02）。
- **实验科学性**：正式 GO/HOLD/STOP 阈值必须来自已批准协议；AI 提出的数值仅为待批准候选；加强效应量、独立样本与区间核查（R02）。
- **科研接力保真**：快速摘要允许因关键证据而超出参考字数；分别记录实验验证、科学结论、批准与执行授权；真实 .md 文件须实际生成并核验（M01）。
- **基金材料真实审查**：只有读取文件、检查实际单元格/公式或计算字符数后才能报告 PASS；语言建议不能冒充官方硬性规定（G02、G03、S02）。
- **论文证据分层**：区分全文、摘要、二手线索和作者资料；不从题名或摘要推导未披露的方法、统计细节（R01、P02、P03）。
- **日常使用效率**：明确检索停止条件、术语优先级及多文件版本追溯（S01、L01、M02）。

**如何使用**：仍按现有目录复制相应 Prompt；在一个工作流中可以顺序调用多个模板，但每一具体步骤仅调用所需的模板。高成本动作需当前任务中的明确授权。修订是基于原始 GitHub Prompt 的结构性借鉴，尚未完成多任务 A/B 效果评测。
