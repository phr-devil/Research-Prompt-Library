# 跨 AI 独立审查（第 8 类的新子栏目）

本栏目与上一级的 [V01 · 目标驱动的算法检验任务规划](../V01_目标驱动的算法检验任务规划.md) 并列，解决**何时启用另一 AI**及**怎样总结当前算法供其独立复核**，不替代研发与正式实验授权。

| 模板 | 使用时机 | 主要作用 |
|---|---|---|
| [V02 · 独立审查触发与范围判断](V02_独立审查触发与范围判断.md) | 持续研发时作为长期规则；出现关键变更或重大结果时 | 按风险选择 SKIP / TARGETED / FULL，避免无效重复审查 |
| [V03 · 算法证据交接与独立复核](V03_算法证据交接与独立复核.md) | 决定进行 TARGETED / FULL 后 | 生成项目状态、证据索引、独立审查任务，交由不同模型核验 |

**推荐流程**：V01 安排研发与验证 → V02 判断是否需要独立审查 → V03 生成交接包 → 独立 AI 实际核验 → 开发 Agent 核实发现并按 V01 修复。已有有效证据应复用，不机械循环。

审查者应能读取原始证据；不同模型的共识并不等于科学证明。所有收费外部服务、私有数据外传、GPU 训练与冻结协议更改仍受原有授权限制。
