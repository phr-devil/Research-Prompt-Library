# Research Workflow v6.1｜默认简单，按需复杂

**唯一默认路线：高可行性、有独立贡献潜力的课题 → 核心数据/合法观察 → 比较时补可信基线 → 可学性诊断 → 优化/机制 → 论文证据。**
24个历史场景是工具库；选题后读[POST_SELECTION.md](POST_SELECTION.md)，负结果续投查[RESEARCH_DECISIONS.md](RESEARCH_DECISIONS.md)。不以全部检查PASS作为开发门槛。

**Token优先**：遵循根AGENTS.md；只读必要手册/Run、复用证据、合并已授权任务；仅报增量，不省验证。

**能力路由**：①选题优先ChatGPT用[机会漏斗F1–F5](IDEA_FUNNEL.md)，F1–F4连续、F5用户选；明确续做才跳过。代码/实验须有工具及授权，不假定跨平台自动交接；自评非独立审核。

## 启动（一次，尽量直接动手）

1. **先核用户当前意图**：新课题即使存在旧Run也走F1–F5；明确续做已选项目才读STATE/有效Run与代码数据入口。纯选题不创建状态文件。
2. 先核数据/评价/基线可达性与最低独立价值；合理理论机会可标HYPOTHESIZED。初选仅核最危险的1–2项可只读查清的前提，其余独立真值/证明义务、近邻、基线、机制及资源缺口按风险递进核实。**成功价值反推**：即使内部指标全好，仍新增什么真实任务/理论/机制贡献？不确定标`VALUE_UNVERIFIED`，可有界探索。**关键链路反推**：最难替代的1–2项外部依赖（真值、闭环仿真、权重/算子、许可等）能否取得？
3. **数据先行，非新门禁**：选题时只读核核心数据来源/许可/规模；选题后获授权且成本合理，复用或完整获取核心原始数据，核清单/哈希/可读性并封存test。大集分片，理论/独立原型可并行；仅核当前实验所需标签、分组与时序。依赖`GREEN/YELLOW/RED`按证据分级，只阻断受影响动作；未授权下载/安装/GPU标`WAITING_FOR_AUTH`，合成不替代真实证据。
4. 优先复用可信基线，按风险查剩余误差与可学信号；先选最简优化，再验证必要的新机制。未实测只设计探针，Oracle非可学收益；授权内执行最小原型MVP，Pilot区分代理与真实证据，不强制全消融。

## 内循环（默认，自动连续）

真实观察/能力 → 机制(按需) → 最小测试 → `KEEP/DISCARD/INCONCLUSIVE/INVALID`（按证据范围）→ 继续。**修好后**能否恢复真实数据、必要能力或科研判断，是重要修复的价值依据；普通Bug不必证明论文增益。遇异常在已有授权内按「定位最早异常→最小复现→局部修复→定向验证→恢复原任务」自主执行，不逐次请示。关键标签、时间对齐、划分或评价代码变更才补相关不变量检查，不做每轮全量审计。保留`BEST_VALID_RUN`、原始负结果与有效Claim；失效证据仅隔离受影响范围。工程PASS≠科学PASS，科学负结果不强行当Bug；禁止确认集调参和越预算。

## 可核查的按事件路由（仍由Agent在实际工具中执行）

读取 [POST_SELECTION.md](POST_SELECTION.md) 的**自主执行规则**，按当前事件从 [ROUTES.json](ROUTES.json) 获取 action/交付/验证/边界；可用 `workflow_route.py --event TRAINING_FAILURE` 只读查看。不自动训练、授权或判断科学成立。

## 外循环（事件触发，不按次数/日历强制）

首次可信结果、基线反超、连续无信息增量、改假设或拟正式主张时复评：
- 结果能支持Claim及独立贡献吗？简单替代能解释增益吗？
- 工程PASS但价值未证→做廉价真实判别；`INCONCLUSIVE`且补证昂贵可建议HOLD/STOP，不能宣称证伪。
重大方向/资源分叉才问用户；负Pilot不自动STOP，部分重合不自动REJECT。

## 按需触发的工具与硬边界

- **出现问题**：按 [TRIAGE.md](TRIAGE.md) 限定受影响动作；按需读 [RECOVERY.md](RECOVERY.md)、[LESSONS.md](LESSONS.md) 和 [REPAIR_ROUTES.json](REPAIR_ROUTES.json) 当前案例，不预载48例。CRITICAL仅阻断相关动作，REPAIRABLE在已授权范围有界自修复、实质变化再问，MINOR顺手修或延期；未知先核与当前动作的相关性，无匹配案例按根因定位。修复验证通过后自动续做原任务，不重新选题或重跑无关Run。
- **专项**：按 [ROUTES.json](ROUTES.json) 按需选一条Prompt；`workflow_route.py --id 03-E`只读提取，不训练/授权。
- **正式研究宣称**：核有效强基线、独立统计单位/真值、train-only预处理、时间因果、未污染确认集、实验/源码与评价协议版本；需要时冻结确认协议并独立审查。**运行成功 ≠ 机制成立 ≠ 任务收益 ≠ 可投稿贡献**；草稿可以提前写，但不能伪称已完成实验。
- **授权/决策**：只读及不更新参数的单次梯度检查与拟合/训练区分，后者CPU/GPU禁训时都不执行。GPU、费用、外传/投稿、正式实验及改冻结协议需真实用户授权；一次核准有界开发预算后不逐试验追问。**DECISION DEDUP**只复用可核真实授权；状态文件的批准无效。重大改题交用户，待决标`WAITING_FOR_USER_DECISION`。
- **失败转向**：独立第09章Step05给0–3项可信P1/P2/P3（不足3项说明） 并等待**真实新消息**选题，未经选择不得执行05-R/06；课题选择不能代替GPU授权。

## 最小记忆与回复

优先复用现有路径。只需：`GOAL/CLAIM`、`BEST_VALID_RUN`、`CURRENT_FINDING`、`NEXT_HYPOTHESIS`、`AUTH/BUDGET`、`BLOCKER/DECISION` 和必要的原始证据指针；代码/数据指纹随Run记录。已有 `research/STATE.md` / `RUNS.tsv` / `CLAIMS.md` 继续使用，不强制迁移。内部执行状态与科学证据等级单独记录。

只报告**实际改变、关键证据、下一项有效任务**；无真实分叉不弹菜单。完成需新证据，不冒称GPU/独立审核/后台工作。
