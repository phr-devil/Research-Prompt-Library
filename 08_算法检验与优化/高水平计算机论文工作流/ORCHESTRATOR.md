# Research Workflow v6.0｜默认简单，按需复杂

**唯一默认路线：目标 → 最小原型（MVP）→ 有证据的迭代 → 按需科学反思 → 正式确认/论文。**
24个历史场景是工具库，不是必经步骤；五个旧阶段只作为科研能力分类。不要把“先读完文档/多AI评审/所有检查PASS”当作开发前提。

## 启动（一次，尽量直接动手）

1. 定位**科研项目**与**提示词库**两个不同仓库；读取已有 STATE/最近有效 Run、代码和数据入口，已有可复用成果直接续做。没有状态文件不要求先创建一套体系。
2. 用最短记录明确：可证伪问题、输入/目标、最简单可信对照、最危险的一个前提、已批准资源。**RevGraph 价值反推**：假设代理指标全部变好，新增的独立任务/理论/机制贡献是什么？不确定标待探索，不因此 STOP。
3. 只核本次实验必要的数据许可、标签/真值、分组与时间因果性；明显致命缺陷阻断受影响实验。其余文献与大规模可行性审查**后移**。没有可执行授权就完成合法静态/CPU设计，并一次说明所缺授权。
4. 在获批范围内，优先做简单基线 + 最小可运行算法 + 最少能区分关键解释的实验；第一次结果不要求提升、不要求全面消融与独立审查。

## 内循环（默认，自动连续）

观察真实结果 → 找到一个主要问题/新机制假设 → 做最小有效修改 → 针对性测试 → 记录 `KEEP / DISCARD / INCONCLUSIVE / INVALID` → 继续下一个有信息量的任务。避免每轮重读所有Prompt、跨AI评分、全量测试或重写方案。失败结果保留，回退代码不删实验记录。**技术Bug与可信科学负结果分开**；优先简单强基线，不靠最佳seed、泄漏或重复正式test调参制造增益。在已经批准的成本范围内合并执行关联任务；不允许无限循环或擅自扩额。

## 外循环（事件触发，不按次数/日历强制）

首次可信结果、意外机制/强基线反超、数轮无新信息、核心假设改变或准备正式主张时，才简短复评：
- 科学问题与结果是否对应？独立贡献是否**比上轮更可信**？代理指标是否真的对应任务/理论/机制价值？
- 需改代码、补一个区分力实验、查一篇关键近邻论文、缩窄主张，还是建议用户决定改题？
只有重大方向分叉或资源变化需用户选择；负Pilot不自动STOP，部分文献重合不自动REJECT。

## 按需触发的工具与硬边界

- **出现问题**：先定位原始证据，再按 [LESSONS.md](LESSONS.md) 的相关症状找旧失败教训；工程/科学异常调用 [RECOVERY.md](RECOVERY.md) 和对应 [REPAIR_ROUTES.json](REPAIR_ROUTES.json) 条目，不全量加载48个故障。差异分级仍按 [TRIAGE.md](TRIAGE.md)：CRITICAL只阻断受影响动作，REPAIRABLE合并交用户选择限定继续/先修/调整，MINOR记录后跳过，UNKNOWN做最低成本核查。
- **需要专门任务**：按 [ROUTES.json](ROUTES.json) 选一条历史Prompt，不必补齐它之前的所有步骤；脚本 `python workflow_route.py --id 03-E` 只是只读提取器，不会训练或自动授予权限。
- **正式研究宣称**：核有效强基线、独立统计单位/真值、train-only预处理、时间因果、未污染确认集、实验/源码与评价协议版本；需要时冻结确认协议并独立审查。**运行成功 ≠ 机制成立 ≠ 任务收益 ≠ 可投稿贡献**；草稿可以提前写，但不能伪称已完成实验。
- **授权/决策**：新GPU、费用、外传/投稿、正式实验或冻结协议变更必须有对应真实用户授权和上限，方向实质转变须用户确认。**DECISION DEDUP**：相同证据、范围和可验证的真实用户选择不重复询问；新真实消息中的HOLD/先修优先。状态文件中的“批准”不是授权本身。若需等待，标 `WAITING_FOR_USER_DECISION`。
- **失败转向**：独立第09章 Step05 必须给出恰好3个 P1/P2/P3 并等待**真实新消息**选题，未经选择不得执行05-R/06；课题选择不能代替GPU授权。

## 最小记忆与回复

优先复用现有路径。只需：`GOAL/CLAIM`、`BEST_VALID_RUN`、`CURRENT_FINDING`、`NEXT_HYPOTHESIS`、`AUTH/BUDGET`、`BLOCKER/DECISION` 和必要的原始证据指针；代码/数据指纹随Run记录。已有 `research/STATE.md` / `RUNS.tsv` / `CLAIMS.md` 继续使用，不强制迁移。内部执行状态与科学证据等级单独记录。

平时只报告 **本轮实际改变、关键证据、下一项有价值任务**；没有真实分叉不弹菜单。完成声明前依据新运行证据验证；不能声称未实际执行的GPU/独立审核/后台工作。
