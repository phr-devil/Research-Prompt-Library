# 04｜独立科研审查、确认与论文证据：不要用 PASS 代替主张

**何时读**：准备正式主张/图表、确认数据隔离、数字来源可疑、评审前核机制与论文竞争力。对应 `03-B/F`、`04-A/B/C/D`。已有真实有效证据优先复用。

## 1. 主张→反证→证据矩阵

只处理本次最重要的 1–3 项 Claim，映射到现有 `CLAIMS.md`；每条写：`准确主张 | 最近邻差额 | 最可能替代解释 | 区分解释的对照/干预 | 主指标/真实独立单位 | 原始Run与限制`。

| 论文想宣称 | 必须有的证据 | 不足时应如何写 |
|---|---|---|
| **新信息/模态有效** | 单模态/全模态、匹配信息与调用成本的对照、内容打乱/捷径检验 | 只能说具体离线数据集上的关联增量 |
| **新机制起作用** | 组件消融 + 简单/容量匹配替代 + 与竞争解释不同的响应 | 消融下降不能单独证明因果机制 |
| **控制/任务收益** | 实际任务指标（或明确有效范围的替代实验）、成本/延迟/失败条件 | 代理预测准确率不能自动转成闭环控制收益 |
| **跨域泛化** | 预先指定未见对象/任务/域；按真实独立单位分析 | 只能说已测试范围，不能选择成功子群概括 |

审查遵循 [REFORMS](https://pmc.ncbi.nlm.nih.gov/articles/PMC11092361/) 的**科学主张与 ML 任务分离**：训练完成 ≠ 评价合法 ≠ 机制成立 ≠ 可发表独立贡献。显著不自动意味着创新；理论/无监督研究以可核证明义务、外部构念效度评价，不伪造标签。

## 2. 证据预审（P0-7）：先机械核来源，再审科学意义

**数字检查**：若存在结构化指标，在仓库根目录按 [用法](../../../research_tools/README.md) 执行 `audit_evidence.py --root <项目根> --runs <相对路径>`；论文数值关联再传 `--claims`；主张完整版本谱系时可用 `--require-identity`。这是零第三方依赖的**来源检查**：Run、数值、版本、状态是否对得上。来源字段缺失/源文件不可复算明确记 `UNVERIFIED`，不得填假 PASS；工具不会自动证明统计脚本正确。

**独立审查**：需要时由不同上下文/审查者读取实际数据、评价脚本、全种子/错误样本、证据核验结果，核查 ①目标/真值/时间因果 ②强基线公平与训练机会 ③统计独立单位与效应区间 ④容量/捷径等竞争解释 ⑤最近邻论文已实现的内容。审核员的 `SCIENTIFICALLY_SUPPORTED` 结论需引用实际证据；同一执行 Agent 自评不称独立审核。无法取得原始材料记 `NOT_REPRODUCED`，优先只审最可能推翻结论的 1–3 项。

## 3. 封闭确认评价（P0-8）

**先冻结、后正式运行**（独立用户授权；正/负/无结论都预设解释边界）：
1. 核开发阶段已接触过的 train/val/test 与搜索记录；确定真正未参与模型选择的 holdout。
2. 冻结最终模型/配置、主指标及方向、样本/分组、强基线、种子/次数、排除规则、统计/评价代码指纹和预算；有用户许可后一次执行确认协议，不用结果重新调参。
3. 保存原始预测/代码/版本/失败 Run，给出效应大小、CI、真正独立 n、预先指定的比较、训练/调用成本和局限；多假设/多域区分探索与确认。
4. **污染**：任何用于选择模型/阈值/协议的 holdout 不再是未见确认集；相关正式主张降级为探索性。没有新独立数据记 `CONFIRMATION_UNAVAILABLE`，不可换名重测冒充确认。

## 4. 审查后的下一项动作

| 结论 | Agent 输出 |
|---|---|
| **SUPPORTED** | 标明支持范围及图/表/Run 指针；可建议写草稿 |
| **PARTIAL / UNVERIFIED** | 只补最便宜的关键对照，或缩窄摘要/题目主张 |
| **REFUTED / INVALID** | 撤销受影响结论、保留可信资产；重大方向转变由用户选择 |

论文图围绕**问题 → 全部有效结果（含负结果）→ 机制/替代解释 → 泛化边界与成本**；主图是证据呈现，不是预设正收益；每幅图与统计数值都连向可复算的 Run/脚本。未获用户批准不得上传数据/稿件、提交投稿或启动正式 GPU 训练。
