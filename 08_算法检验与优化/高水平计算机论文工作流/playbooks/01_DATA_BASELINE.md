# 01｜真实数据、独立真值与强基线操作手册

**加载条件**：首次接触数据、真实任务/标签有歧义、基线不可比较、数据版本或评价口径改变。对应现有 `02-A/B/C` 和 `03-B`。前提许可/数据未知时做最低成本只读核对，不擅自下载、迁移或运行受限资源。

## A. 把科学主张翻译成数据契约

1. 用一句话写 **H**：例如“在相同可用历史信息与触觉调用成本下，策略A比B具有更高真实任务成功率”。分别列 `Input[t]`、`Target[t+h]`、`Decision[t]`、部署时已知的信息、缺失值意义、输出单位与预期取值。
2. 检查数据字段/许可证/来源/时间戳/采样频率/同步方法/物理单位/episode与对象ID/标签生成规则/规模。区分真实注释、脚本派生代理、模型预测、未来动作/奖励；出现标签与输入同源循环时缩窄主张或停受影响路线。
3. 以避免泄漏的实际独立单位拆分（对象、人员、机械任务、环境、会话或日期，具体由主张决定），先固定开发/验证/未接触确认集；纯时间预测需保证训练窗口不跨越未来边界。标准化、特征选择、缺失值填充和阈值拟合在训练集拟合；动态在线标准化只能用当前过去。
4. 指标至少包含一个与中心主张直接相关的 **primary metric**；另列辅助代理/资源指标，方向和单位、有效样本数、独立统计单位、评价频率与统计方案。分类优先考虑类别不平衡下的 AP/PR-AUC 与校准；回归优先 MAE/RMSE 与样本/时间跨度的定义；闭环任务优先成功率/约束违例/成本等。指标不是无条件通用清单。
5. 关键技术依赖（闭环仿真器、专有标签、GPU算子、权重）先按 `GREEN/YELLOW/RED/UNKNOWN` 排险，端到端 smoke 需到**实际评价输出**，不能把 forward/pass 或合成闭环视为真实可行性。

**交付**：与已有文件映射的 10 行以内 data/evaluation contract；必要原始证据指针。特别标明“本数据能够证明什么、不能证明什么”。

## B. 建立公平的简单与强基线

按任务从低到高选，不盲目运行全部：常量/多数类、Persistence（时间预测）、线性/Ridge/Residual-AR、树模型、简单 MLP、标准视觉/时序 backbone、最近邻可复现强方法。baseline 的选择必须匹配具体预测任务与物理含义。

| 必须核对 | 可执行判断 |
|---|---|
| 任务一致 | 同一 target/horizon、时序容差、正负定义、后处理、评价脚本 |
| 信息一致 | 对照可用的模态、历史、动作和未来信息明确且公平；Oracle 只作上界 |
| 预算一致 | 同一训练/开发划分，合理匹配调参和训练资源，报告无法匹配的差异 |
| 样本一致 | 同一 test 单位及排除规则；禁止因某法失效而隐式改变分母 |
| 重现一致 | 代码/配置/数据版本、seed、原始预测或可复算统计、推理/训练成本 |

**最低成本次序**：先用官方或现有评估器复现一个可信基线→检查其输入/目标→再实现目标新算法。若强基线超过新法，优先检查科学假设和评价，不急着堆模型。

## C. 可改写为项目测试的具体断言

- `set(train_group_ids) & set(test_group_ids) == set()`；有 val 时三组两两互斥（若目标是跨任务泛化，则按任务分组）。
- `max(input_timestamp) <= decision_timestamp`，并确认预测目标满足 `target_timestamp > decision_timestamp`（仅对预测未来的任务适用；零步/当前时刻任务需另定义）。
- `fitted_preprocessor.groups subset_of train_groups`；统计量不得来自 val/test、整段未来轨迹或确认集。
- 常量/打乱标签、错误时序、模态空白等负对照应该按预先机制预期表现，**不是规定必须降低到随机**。如果负对照同样显著，先排查捷径、场景线索、标签同源。
- 若样本存在同一 episode 内高相关帧，bootstrap 应以 episode/对象等合法独立单位聚类，不能把数万帧当独立 n；随机种子不等于新的独立物理样本。
- 可选自动测试：读取最小真实 batch、检查 shape/dtype/单位、重算一个预测指标、证明模型和基线的样本 ID 与 horizon 完全一致。

上述为**需按数据结构适配的测试意图**，不是可以直接照抄运行的现成测试，也不能以人工填写的 PASS 代替执行日志。

## D. 通过/无结论/阻断

- **READY**：数据主张匹配、独立标签/时序/划分清楚，有实际读取与可复算基线；允许开展对应 Pilot（仍需资源授权）。
- **LIMITED**：数据可用但只有代理标签或仅离线任务；继续合法开发，但相应任务/机制主张标 `VALUE_UNVERIFIED`。
- **INVALID/BLOCKED**：核心标签循环、不可解除的数据泄漏、确认集已用于调参、核心闭环评价不可获得等影响对应声明；保存有效资产，不换名字强行通过。

若缺专有/远程数据，标 `WAITING_FOR_DATA` 并给出一次最小具体请求，不无界补合成样本。
