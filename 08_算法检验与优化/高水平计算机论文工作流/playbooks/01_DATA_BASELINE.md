# 01｜数据、评价器与强基线：先证明比较合法

**何时读**：需真实数据、强基线失败、标签/时钟不明；复用有效Run，关联`02-B/03-B`。

## 1. 先锁定真实可检验任务

**数据先行（非门禁）**：只读核核心数据版本/许可/清单/体积；获授权后复用或完整获取所需原始文件，核数量/字节、哈希/CRC、解压及ID覆盖。大集分片，未齐`PARTIAL_DATA`；无授权`WAITING_FOR_AUTH`，待数据`WAITING_FOR_DATA`。封存test只核存在/校验值，禁选模；理论/合法MVP可并行。下载≠真值有效。

**初探仅核当前动作必要项**，未知记UNKNOWN；正式比较才补六项：

`Claim | Input(t)与部署可见信息 | Target(t+h)/独立真值来源 | group与时钟/单位 | split与预处理拟合范围 | primary metric及分母`

- 查看字段、许可证、对象/episode ID、时间戳、频率/异步偏差、缺失、标签生成代码。**同源派生标签≠独立真值**；无真实闭环记录不能把离线预测称为控制精度/成功率。
- 按科学泛化目标选独立分组（对象、任务、受试者、会话等），使 train/val/holdout 不交叉；需要时间预测时确保输入仅为 t 前可见值、目标时间严格按任务定义。标准化/阈值/特征筛选仅 fit train；验证/测试不参与拟合。
- 一个真实batch核shape/dtype、单位、NaN、时间/ID/标签；手算指标并保存评价器指纹。

## 2. 强基线复现合同（P0-3）

**分层基线**：初探仅需简单可信参照（常量/Persistence/Ridge/AR等），未能比较须说明；有残差、拟加大投入或确认论文时再补具名强基线及公平调参。仅跑通基线≠论文贡献。

| 对齐维度 | 必须相同或写明不能比较的原因 |
|---|---|
| **任务** | target、horizon（真实时间还是帧数）、时序容差、正负定义 |
| **信息** | 输入模态、历史窗口、动作/未来信息、可用触觉次数/成本；Oracle 必须注明特权信息/可行策略集；未证明最优时仅作诊断参考 |
| **评价** | 相同 sample/group IDs、有效掩码、排除规则、metric 代码和分母 |
| **训练公平** | 可比数据、合理且透明的调参机会/训练资源；不能暗中不给基线调学习率 |
| **可复算** | 官方方法/版本或已验证 Run、数据/配置/协议指纹、预测或指标来源 |

**资源预筛**：先核本轮不可替代依赖；大投入前核官方最小配置、权重/显存/许可，替代结果不得冒充原强基线。

复现按`官方/有效Run→重算评价→关键差异诊断`；不可比论文分数仅参考。失败记`STRONG_BASELINE_NOT_REPRODUCED`，注明可运行替代与局限，不以缩水实现宣称SOTA。

**最小测试**：分组不交叉、线上不看未来、train-only拟合；按`sample_id,group_id,target,prediction,valid_mask`对齐，协议变化仅重算受影响Run。

## 2.5 性能空间诊断与机制可利用性（按需）

**可学性最小探针，按需而非新门禁**：先确认信号/真值、group数量、简单基线和剩余误差；有残差或拟高投入时用合法开发组学习曲线、分组残差/简易探针检查可用信息，再核同一开发协议的`B_simple / B_strong / O_reference(可选) / P_feasible(待核)`；未知记UNKNOWN。探针失败≠不可学习，不能宣称闭环收益。

- **配对残差→机制线索**：公平调参`B_strong`，按`sample_id/group_id`核错误交集、分歧、条件误差、组级CI/效应；精度不足只形成探索假说，**不能凭切片点估计直接投入昂贵GPU机制**。用合法先验做廉价探针，开发切片尽量由独立开发组复核，冻结确认集不选片。无原始预测标UNKNOWN；互补错误≠可部署融合。
- **Oracle不等于可学增益**：`O_reference`若见未来信息、实际决策不可得信号或另一成本/策略集合，只作特权诊断；没有最优性证明的 Oracle 不是数学上界；不同目标/成本不得直接计算gap。缺参照记`O_UNKNOWN`。
- **P_feasible非承诺**：从误差/理论推测信息、归纳偏置、优化或容量机会；按部署可见信息、简单替代及不同预测选廉价检查。动态门控核决策前信号与可辨识性；探针失败≠不可学，未知写`UNKNOWN`，不凭Oracle推收益。
- **因果范围**：离线遮蔽、观察记录和代理分数通常不能直接识别未执行动作的控制收益；需要闭环/随机化或有证据的可识别性条件，否则只宣称离线预测。
- **分叉**：理论先验/新现象可低成本探索；机制对照才需不同预测。缺最终真值只限制正式Claim；无信息且成本失衡才HOLD。

## 2.6 正控

`CORRECTABLE/PREDICTABLE/DISTINCT`：干预、预测、对照；详见POST_SELECTION。

## 3. 判断与交付

- `READY`：目标所需评价/证明、数据与简单基线可复核；仅指准备程度，Pilot仍需真实授权。
- `LIMITED/VALUE_UNVERIFIED`：仅代理/离线评价或证明不完整；可探索但须限定Claim。
- `INVALID`：证据因标签循环/泄漏等失效；`BLOCKED`：相应主张/动作缺必需真值、闭环或许可；`WAITING_FOR_DATA`仅表示待数据，不算科学反证。保留不受影响的合法离线Claim。

**只交付**：初探写合法数据、观察/简单参照和证据指针；正式比较才补六项合同及强基线表。
