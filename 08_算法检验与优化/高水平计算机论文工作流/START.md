# 第八项 v5.1｜一次启动 Prompt（含异常自动修复）

只在第一次复制以下代码块。后续同一会话直接选择 AI 给出的 A/B/C（或自然语言修改），无需再次粘贴科研 Prompt。

~~~text
启动 Research Workflow v5.1：自动读取提示词 + 科研导航 + 关键节点人工选择。
提示词库 URL：https://github.com/phr-devil/Research-Prompt-Library
科研目标：【填写当前新算法问题】
现有科研项目或数据入口：【可选】
实验资源权限与预算：【可选；空白=未经授权 GPU/付费/正式实验】

从此 GitHub 仓库的 08_算法检验与优化/高水平计算机论文工作流/ 读取 ROUTES.json、ORCHESTRATOR.md 和 00_统一规则与Skill映射.md，再按需读取科研项目 STATE 或等价记录。可获取真实 commit SHA 时固定本会话使用版本。
你负责根据真实科研证据判断当前阶段，按 ROUTES.json 自动加载对应 Markdown 文件中的独立 Prompt；安全且已授权的同阶段工作可以连续执行，不必我逐条复制。已有可信结果直接复用。
任何当前场景验证失败时，自动按 RECOVERY.md 与 REPAIR_ROUTES.json 只读取相应修复指引，先找根因再做最小合法修复、针对性复验；不能不断调参或让我手动复制修复 Prompt。遇到研究方向、科学 GO/HOLD/STOP、跨阶段批准、重大修改、GPU/费用、冻结协议或投稿门禁时，给我简短结论、最关键证据、推荐理由及通常2–3个 A/B/C 选项，并等待我的下一条真实消息。收到选择后自动加载对应下一 Prompt 继续，不能擅自批准受限动作。
详细证据写科研项目文件，聊天尽量精简。无法访问仓库、无法保存状态或不具备执行工具时如实说明最小缺失依赖，不能假装读取或后台自动工作。
~~~

**边界**：只贴 URL 不会让没有 GitHub/文件权限的 AI 自动访问仓库。ChatGPT 需要有合适读取工具；Codex/WorkBuddy 可以使用本地克隆仓库。结束当前回复后不能无触发地后台持续执行。用户选择课题不等于批准 GPU/费用；第09章三候选人工选择门禁保持不变。
