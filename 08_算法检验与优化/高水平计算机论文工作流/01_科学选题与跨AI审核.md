# ① 科学选题与跨 AI 审核

**负责人**：ChatGPT 主责；另一个隔离会话/模型或 Codex 独立反证；你批准。

**阶段参考**：RS-P/RS-I/RS-S/SPS 主要 `[阅读参考]`。仅匹配当前任务加载相应 Skill。

## 01-A｜候选题目与高水平论文定位

**触发**：必做：新题或方向重选  
**执行者**：ChatGPT  
**Skill**：RS-P + RS-I + SPS `[阅读参考]`

```text
目标：不是“提出新网络”，而是找一个能用可信证据区别于最接近论文的科研问题。
输入：研究方向、可用 GPU/时间、公开数据约束、禁止操作、希望的研究社区。
执行：①联网检索最新+经典重要论文并核对原文；②列出现有技术的具体失败点；③提出不超过3个命题，每个给一句可证伪主张、最近方法、公开数据/外部真值、强基线、最先失败的前提；④推荐一主一备，并区分理论上限和当前证据。
交付：STATE.md 选题草案 + 5–8条最关键的近邻来源（DOI/官方链接、确实对照的内容）。
停止：完成命题比较即止；不生成完整架构、不实现、不训练，不编造 JIF 或命题成功概率。
```

## 01-B｜新颖性碰撞与基线核验

**触发**：必做：存在候选命题  
**执行者**：ChatGPT 或另一 AI  
**Skill**：RS-S `[阅读参考]`；RS-Q 仅可选

```text
目标：尽可能早发现“已有人做过/强基线足够好”。
输入：一项候选主张和近邻论文清单。
执行：①按问题、机制、输入/输出、评价数据四轴分解创新；②从标题同义词、方法签名、最强竞争方法进行交叉检索；③对最接近3–6项工作核查其真实实验、代码和限制；④写出一句“我们相对 X 真正新增 Y，需要用 Z 证明”。
交付：近邻对照表 + DISTINCT / OVERLAP / COVERED / UNCERTAIN（附原始来源），强基线清单。
停止：确认创新差额和关键未核实点，不写大篇相关研究、不重复搜索明显相同论文。
```

## 01-C｜论文级算法骨架与独立反证

**触发**：必做：新颖性未被完全覆盖  
**执行者**：ChatGPT 设计 → 独立 Codex/AI 反证  
**Skill**：SPS `[阅读参考]`；ARA 在独立审查时参考

```text
目标：只设计使核心主张可检验的最小算法骨架，而非一次写完所有模块。
设计者执行：①定义输入、目标、时序、物理/数学假设；②将每项贡献映射到至少一个强基线/消融/外部真值；③识别最危险前提、备选解释、允许的最小试验；④给出可复现公平比较和预算边界。
独立审查者：不要拿设计者自评作为真值；检索近邻论文，针对创新性、循环标签、因果时间、数据分组、基线不公平、过度复杂列出最多5个实质缺陷及反证方法。
交付：研究合同（假设/贡献/对照/最小实验/主要阻断）+ ACCEPT/REVISE/REJECT 建议。
停止：形成足以执行阶段②的方案；未批准不写完整代码、不重复跨 AI 空泛评分。
```

## 01-D｜已发表或数据无法支撑时的最小转向

**触发**：条件：创新被覆盖/外部真值缺失/资源明显不符  
**执行者**：ChatGPT → 你  
**Skill**：SPS Problem Inversion `[阅读参考]`

```text
触发事实：[致命问题及其原文/数据证据]。
先判断此问题是否真的使原主张失效；若是，比较“换评价问题/换可得数据/终止”三种最小路径。每条只回答：是否形成独立贡献、需要的额外验证、成本和新风险。
交付：最有价值的一个修正方向或 STOP 建议，以及要更新的 STATE.md 字段。
停止：只提决策，不自行批准科研方向变化。
```
