# 科研机会→独立贡献→算法→实验｜Agent 自主选题 F1–F5

> **适用**：用户只有宽泛领域，希望比较多种新课题，尚未选定可证伪问题时，按需启用。**不是**原型研发的新门禁。已有明确命题、有效实验或获授权MVP时，直接沿 [ORCHESTRATOR.md](ORCHESTRATOR.md) 继续，不重新走漏斗。
>
> **方法参考**：[ARIS idea-discovery](https://github.com/wanshuiyin/Auto-claude-code-research-in-sleep/blob/main/skills/idea-discovery/SKILL.md) 与 [idea-creator](https://github.com/wanshuiyin/Auto-claude-code-research-in-sleep/blob/main/skills/idea-creator/SKILL.md)。借鉴“先发散、再用证据收敛”，**不是安装/运行 ARIS**，不能把 GitHub Star、LLM评分或Pilot代理指标当作顶会成功率。

## 一次运行的选择规则

- **选题探索**：F1→F4优先由具备文献检索能力的ChatGPT或当前Agent在同一会话连续执行，不逐步确认、不要求切换平台或建文件；F5由**真实用户选题**。未读取到原论文/仓库则标UNVERIFIED，不谎称查新完成。
- **用户要求继续已有明确科研主张**：跳过F1–F5，只调用 01-B/C 等必要专题或按v6.1在授权范围直接执行MVP。
- **第09类失败项目挽救与转向**：沿独立的[第09章](../../09_失败算法项目挽救与转向/README.md) Step05/05-R人工选择合同运行；本漏斗不能替代或提前批准该门禁。
- 无固定数量配额；同质/无证据候选不得凑数。F1-F4可合并检索与分析、复用文献，遇到明显关键障碍先核1–2项即可，不要求每个候选完成全文查新。

| 阶段 | ChatGPT的任务 | 目标输出（非硬性） | 当前证据级别 |
|---|---|---|---|
| **F1 科学机会发现** | 可从具名失败、物理/理论假说、跨域迁移、未解释现象和合法数据资产发现问题；区分OBSERVED/HYPOTHESIZED，不必先找到已发表失败案例。 | 不按网络名字凑数；保留出处和真实失效条件 | 论文/资料级 |
| **F2 可证伪发现与替代解释** | 每个机会先写「若成功，新增哪条可复核的科学知识/任务能力」，再提出相互可区分的机制解释；算法结构只是备选工具，记录共同DATA/TRUTH、科学假设、平台依赖。 | 优先保留不同研究问题和可区分解释，不按网络名称或命题数量凑数 | 假说级 |
| **F3 机制机会与真值轻筛** | 只读轻筛最危险的一个共享前提、合法探索路径与简单替代；强基线收益、正式真值/统计、正控及可辨识性按Claim风险后续核实。 | 保留科学上不同的机会，逐项标出最危险且可检验的假设 | 轻筛级 |
| **F4 论文贡献与廉价证伪** | 对优先项先核1–2项具名近邻、1–2项可只读查出的致命依赖与一个最廉价反证；完整实验预算/正式统计和强基线训练留到选题后按授权推进。 | 0–3项RECOMMEND/EXPLORE候选；不能核实写UNKNOWN，允许零正式推荐 | 推荐前证据级，非实验PASS |
| **F5 用户选题** | 分别展示RECOMMEND正式推荐和EXPLORE研究线索，说明NOT_READY原因；仅用户明确选择后继续，保留高风险探索选择权；选择不等于GPU/正式实验授权。 | 用户选择0–1项或要求继续找；不强制有推荐 | 人工决定 |

**探索准入比例原则（见[续投与止损](RESEARCH_DECISIONS.md)）**：
**宽进、分层核验**：`EXPLORE`仅需合理文献/理论/物理依据、可证伪主张、合法廉价探索路径，且无已证实的不可替代致命阻断；无需已证明算法增益、强基线剩余空间或完备统计功效。探索阶段可用代理/自监督目标或合成正控验证局部机制，但必须标 `PROXY_ONLY`，不支持正式任务/因果Claim。能够只读核实的不可替代阻断仍应提前排查；正式论文标准完全不放宽。

EXPLORE不是“缺完整证据所以不值得动手”，而是有可证伪价值、合法验证路径且未证实不可替代致命阻断时，**允许用户真实选择并启动已授权的有界MVP**。不能以新模型尚无性能增益、未全部查新、多seed/外部实验未完成为由阻止探索；F4先区分可只读查清的致命依赖与必须靠研发才能发现的科学未知。RECOMMEND仍需明确更可信的依据；NOT_READY只限**已证实的当前Claim阻断**。进入论文确认的强基线/统计与创新性标准**不降低**。没有用户选题与训练授权时仍不得启动CPU/GPU拟合。

## 选题推荐的证据校准（仅嵌入F1–F4）

**F1 机会来源**：以具名强基线错误切片、公开反常、物理/理论推论、合法数据关系和可迁移机制为并列检索起点。先记录`来源/版本 → OBSERVED或HYPOTHESIZED → 未解科学问题`。Future Work、GitHub Star、LLM打分和新模块名称不是实证。并非所有课题都必须以性能缺口为目标，理论和新评价问题可以用相应可检验义务替代。若多项候选依赖同一个未证真值/平台/机制，只做一次不同来源的定向搜索，不换网络名字凑数；无可信来源时允许零推荐。

**F2/F3 竞争解释**：每个机会写`中心Claim → 已有证据 → 最强简单解释 → 可区分的正控/合法观察`。将证据分开标`已实测现象 / 可核文献或物理依据 / 只读资源条件 / 未实测算法增益`。优先确认最强基线剩余空间、真实标签、决策前可用信息和独立组级统计；后两者缺失不允许用事后Oracle或帧数代替。

**F4 推荐而非综合评分**：只对最终主候选核实中心科学价值、具名最近邻差额、独立验证链、关键资源依赖与最小判别实验，给`STABLE`（已有可复核现象、真值和合理证据路径）、`FRONTIER`（高价值但核心机制待核）、`RESERVE`（先做廉价预检）研究角色。角色不等于概率、影响因子或准入状态，不能仅因能训练就称STABLE。

- `RECOMMEND`：关键问题、真值或独立证明义务、决定性实验的可达性和相对具名工作可辩护的价值有可信依据；可尚无新算法的实测增益，但必须清楚标注核心未知和降级条件。
- `EXPLORE`：有价值但关键机制、信息、资源或近邻差额待核；必须有合法、低成本、足以改变决策的检查，不能包装成稳妥论文。
- `NOT_READY`：原Claim的核心真值/资源/独立价值存在已核实且不可替代的致命阻断；只限当前Claim，不代表整个方向失败。UNKNOWN不自动否决，部分近邻重合不能直接判COVERED。

**排名优先考虑证据和总研发风险**，不要把LLM评分转换成录用概率；明确哪些机会依赖共同前提。历史失败库只能提供风险假说，不能把后来得到的结果伪装成当时已知信息；过去时点证据不完整的案例标`RETROSPECTIVE_UNVERIFIED`。局部正结果和高风险但可检验的创新应保留。只有用户要求评估选题规则时按需读取[历史选题检验样例](SELECTION_AUDIT.md)，该文件不是每轮必读关卡。

## 筛选原则：推荐质量优先于候选数量（不增新阶段)

1. **证据驱动而非失败驱动独占**：F1可从具名失效、跨领域可迁移机制或合法但未用的信息/关系/真值资产发现机会；迁移须写**原领域有效前提→本任务对应结构→可能失效差别**，资产须说明部署可见性与独立价值。`OBSERVED`需可核来源，未知写`HYPOTHESIZED`；Future Work/LLM评分/模块名不是证据。
2. **多样性以独立科研机会为单位**：F2记三类共因依赖`DATA/TRUTH | SCIENTIFIC_ASSUMPTION | PLATFORM`；F3对共享同一未证前提的命题分组。多个架构可保留，但不得当作互不相关的论文机会；已被历史证据证伪的前提必须点出来源与适用范围。
3. **数据—主张双向匹配**：实证监督任务写`Claim → observable → independent truth → legal split/metric → dependency`；理论/无监督/机制发现写相应的可核证明义务、外部构念效度或独立干预证据，不能硬造分类真值。数据可下载≠真值适用；离线演示≠反事实控制收益；只有代理标签时先缩窄主张。核心依赖按已证据可行/待实测/已阻断分级。
4. **最近邻与成功价值**：初筛先看1–2项最直接同机制近邻（不是查新完成保证），关键重合争议或正式论文Claim前再扩到3–5项；`DISTINCT`有可核独立增量，`OVERLAP/UNCERTAIN`允许研究，`COVERED`须指明具名工作已同时覆盖原贡献及拟定增量。相同任务/数据/Backbone或部分模块重合不自动否决；假设所有代理指标提升仍须说明论文增量。
5. **一套证据口径贯穿F4/05-R**：只把**已可只读核查的核心前提**前置F4，正式实验效果、训练强基线和深度细化留给选题后。`UNKNOWN`不得写成已证实可行；同时不得把缺实测写成科学失败。最难替代的真值、闭环、环境、权重或许可优先排险。
6. **分级推荐，不伪造可信候选**：`RECOMMEND`=创新差额、真值评价与关键链路有可信证据，剩余未知有有界实验路径；`EXPLORE`=重要前提未核，值得低成本探索但不是稳妥推荐；`NOT_READY`=已证核心阻断或缺乏可辩护贡献。等级评估的是研发准入，不是新算法效果或论文接收概率。用户可主动选择EXPLORE；0项RECOMMEND也必须如实报告。
7. **限制审查投入**：F1/F2紧凑筛选，F3按共同风险核最致命未知，F4只对最优先项做定向核证；不重做已可信的查新、不默认多Agent、不强制Pilot。缺GPU/真实数据授权只设计实验，不运行。按项目价值而非满额候选决定工作量。

## 从科学发现到高水平论文：推荐前的三个判断（不增阶段）

1. **发现优先**：先写一句「当前共同认识是什么 → 尚不能解释/解决什么 → 本研究希望证明哪条新知识或真实任务能力」。贡献可以是新机制、可信失效规律、理论结论、新评价问题或可复现跨域收益；若只是网络堆叠、内部代理评分或已知方法小改，先重构科学命题。重要但未见实证的方向可标HYPOTHESIZED，不因尚无论文发现而一票否决。
2. **机制机会**：说明最强简单/近邻基线的失效条件、新机制新增的信息**或同信息下新的归纳偏置/训练目标**、部署可用性与成本，以及简单替代能否解释；动态选择区分特权Oracle参考、合法决策前可观测信息与可能可学习的策略。没有实测时只写「机制机会 UNKNOWN + 最廉价区分检查」，**不推断可达增益或自动停止**。细节由[机制设计](playbooks/ALGORITHM_DESIGN_REFERENCE.md)和[数据与强基线](playbooks/01_DATA_BASELINE.md)在选题后按需开展。
3. **论文—实验反推**：先草拟「中心Claim → 对应的独立评价/证明义务 → 公平基线 → 决定性对照或失败边界 → 候选主图证据」；主图只是检验计划，必须保留阴性/无结论及不利结果，不得为预设故事挑选结果。如果全部实验按预期成功，论文相对具名近邻是否仍有新增价值？没有则改命题，而非再造更大Backbone。资源与外部依赖排险只查最关键1–2项，未经授权不训练。

Agent 默认连续完成F1–F4（不需要用户逐步粘贴Prompt）；真实用户在F5决定课题。优先交付**一个**最可信的科学机会及最多两个本质不同的备选，若只有EXPLORE须如实标注；停止规则基于证据而非固定产出数。

### F4 可信推荐最低证据（原步骤内完成，不增加审核关卡）

- **查新覆盖按风险扩展**：初筛先核1–2项最直接近邻，只有真实跨术语覆盖风险再检引文和同义词；论文Claim正式确认前再完成充分查新。不重复已有可信检索。
- **机制差额核查**：对最可能覆盖中心Claim的具名近邻核方法/实验/代码中的实际机制，提供可解析论文/代码出处及具体差额；不是查够固定篇数。只有论文标题、摘要印象或LLM记忆时记`NEIGHBOR_UNVERIFIED`，不可把`COVERED`或`DISTINCT`写成已核实。若关键机制差额仍未知，降为`EXPLORE`并给最小查证动作；不因部分重合直接否决。
- **资源与决定性实验**：F4用用户当次资源粗估成本并只核能只读排险的关键依赖；写`中心Claim→关键证据→依赖→廉价核查/替代方案`。获授权准备正式大量实验时才补完整预算、统计和强基线复现，不只证明模型能forward。**仅对不可替代的外部平台**零训练只读核官方支持矩阵与当前OS/Python/驱动/CUDA/图形ICD/编译ABI、权重/许可；逐项引用官方依据或既有真实Run。沿用依赖`GREEN/YELLOW/RED`：已证实不兼容且无替代才RED，未能实测或文档缺失为YELLOW/`RESOURCE_UNKNOWN`，不凭推测判RED；无需安装或训练。执行包络仍为`WITHIN_BUDGET / NEEDS_SCOPE_REDUCTION / EXTERNAL_DEPENDENCY / UNKNOWN`，不能将不完整强基线冒充原版。
- **独立反驳按风险触发**：投入成本高、机制差额有争议或真值/闭环链路极脆弱时，可请求另一上下文/审查者只读核最强覆盖证据、关键真值和最低成本反证；实际不可获得就标未独立复核，不能虚报PASS；不要求默认多Agent。
- **论文价值承诺边界**：IF或投稿目标只能作为条件性匹配，不能推算录用概率。最终必须给主候选一个`Claim→可核近邻增量→合法证据→最廉价Pilot/失败边界`的路径。

### F4 机制链三问（在原F3/F4完成，不新增关卡）

对主候选按**中心Claim所需**做三项简短检查；在ChatGPT选题阶段只读核依据与最低成本实验**设计**，不运行训练：

**三问不是全部PASS的前置门禁**：先核最危险的一项；其余标UNKNOWN并写触发条件。物理正控、预测探针与强基线实测在用户选题、获对应授权后分批验证。

1. **可纠正性｜正向对照**：有错误/性能缺口，不等于拟议干预能纠正。明确干预单位、独立真值及可控正控（例如逐枚IMU施加已知旋转，检验参数恢复误差和真实任务指标）。熵下降、loss下降、模型置信度升高均不能代替真实纠正；合成正控只支持指定干预的实现与可辨识性，不直接证明真实域效果。
2. **可辨识性｜决策前证据**：仅对校准/动态选择等需要判断“何时、如何干预”的Claim，列部署决策前真实可用的输入与合法历史；用最便宜的预测探针对照时间/工序/缺失捷径，检验干预的净收益或参数是否可以预测。事后Oracle/rescue不构成可部署收益，额外传感器总体有益不直接支持动态门控。
3. **论文独立价值｜竞争简单方案**：正控与可辨识性即使都成功，在同信息、同评价、相近成本/激活预算下，是否仍可合理胜过固定策略、简单校准/线性探针及具名最近邻？若干预总是有益，为什么还需动态选择？说明最低有意义效应与独立组级精度的可行性，缺实证写UNKNOWN。

**推荐分级**：仅凭“确有问题、存在特权Oracle空间、网络能训练”，不可将依赖未核关键机制的候选包装为稳妥`RECOMMEND`，宜标`EXPLORE`并给最廉价反证。F4**不要求正控已经实测**；可信物理原理/具名独立证据、合理可辨识条件和可执行的Pilot设计可支持有条件推荐。已知不可辨识且无替代时缩窄Claim或`NOT_READY`；未实测不等于科学证伪。非动态策略课题以相应可证伪机制/理论检验代替，不机械套门控框架。

## F4 反向论文审查：先判断命题值得验证什么

不增加新轮次。在 F4 对最优先的候选各做一次 **假设结果成功、审稿人仍不认可** 的压力测试（ChatGPT，只读文献/数据说明）：
1. **最近邻反驳**：列具名方法与相同任务/信息/评价条件下已做出的贡献；用真实出处标清差额，未知为 `UNCERTAIN`。
2. **价值反驳**：即使代理指标提升，是否独立揭示任务价值、可检验机制或新知识？若仍不成立，缩小主张或降优先级。
3. **可检验性反驳**：主指标是否存在独立真值和合法评价？尤其对动态控制，离线被动记录能否识别策略改变后的结果；无法识别时只建议离线结论。
4. **空间反驳**：先写最强可信基线、可得的参考上界及最大未知；缺数据时列最廉价的**潜力诊断**而非估计成功率。Oracle 如果含未来信息，仅作特权参考，不能承诺可达收益。
5. **最致命实验**：预写最廉价的判别实验（竞争假说、可观察结果、合法独立单位/最低可检出效应、预算与退出/缩窄条件）；哪些结果只得`INCONCLUSIVE`、哪些才否定当前机制？设计不等于获批运行。

**从论文到首轮实验的可执行锚点**：F4优先对主候选标明可复用的公开基线/仓库与合法评价入口、当前可验证的最小反例，以及哪个关键变量属于可修改机制、哪个评价资产须保持不变；如果没有可运行证据，只列出选题后验证所需条件，不声称已完成复现或数据可用。候选真实差别应是科学Claim或可区分预测，而不是换骨干网络/名字。

**推荐前一致性审计**：若关键平台RED且无替代，或中心Claim必需真值/合法评价确证缺失，不得RECOMMEND原主张；未知但可低成本排险的标EXPLORE/附限定条件，不把只读核验冒充平台端到端PASS。逐项比较“F4已知”与“05-R之后才需要实证”的边界；禁止把本可通过论文/数据文档发现的致命前提故意后移。可利用性能空间须区分特权Oracle参考与部署时可用信息；没有真实数据时仅列最廉价诊断，不虚构`P_feasible`或增益。将同组候选共享失败条件写给用户。

**输出**：每个F4候选按下方**最小研究合同**交付，保留具名反驳、基线/上界证据等级、关键平台GREEN/YELLOW/RED、决定性实验在预算内可否完成、低成本排险与主张边界；不省略资源条件，未知写UNKNOWN，不重复撰写一份长报告。提出一个证据相对充分的主候选和可选一个高潜力备选，不强凑数量；F5 仍由用户决定。选定后读取 [01 数据与基线](playbooks/01_DATA_BASELINE.md) 执行真实的性能空间诊断，F4 不擅自运行训练。

**论文组合适配（轻量判断，非配额）**：有多个在研项目时，仅比较候选在组合中的角色（`STABLE`：独立真值、可运行强基线与投稿证据路径明确；`FRONTIER`：高价值新机制但存在关键未知；`RESERVE`：低成本待核）及与现有项目共享的数据、平台、标签等**相关失败风险**。避免全部依赖同一未验证条件；不强制项目数、角色比例或退出高风险创新。F4 同时标一句`论文贡献类型/目标读者/必须取得的关键证据`，投稿渠道只做方向适配，正式期刊规则留到05-A核查；F5仍由用户选题。

## F4 每个最终候选的最小研究合同

`来源与OBSERVED/HYPOTHESIZED | Claim及STABLE/FRONTIER/RESERVE角色 | 最强简单基线与具名近邻差额/核验级别 | 独立真值/统计单位 | 可纠正性/决策前可辨识性（适用时）与竞争解释 | 最廉价判别实验/失败边界 | 关键资源及决定性实验可达性 | 论文独立价值 | RECOMMEND/EXPLORE/NOT_READY`

解释“负结果”究竟证伪假设、揭示边界，还是因为样本不足没有统计分辨力。论文潜力只能表达**条件性的定性判断**，不得用LLM分数冒充接收概率；无充分证据时如实给1–2项或0项候选及下次搜索应聚焦的位置。

**输出与状态分开**：候选逐项用`RECOMMEND/EXPLORE/NOT_READY`；0项可辩护候选时`INSUFFICIENT_CREDIBLE_CANDIDATES`并停，不使用`READY_FOR_USER_SELECTION`；有1–3项则展示后`WAITING_FOR_USER_SELECTION`，`READY_FOR_USER_SELECTION`只代表材料已备齐、不能表示用户已选。没有RECOMMEND但有EXPLORE时明说“目前无可信正式推荐”，允许用户选择探索或继续检索。只有用户正式选择后才可根据现有授权拟定02-A最小真实验证；如果主张实质变化，还需用户另行确认。F5不是第05类论文阶段，也不是第09章Step05。
