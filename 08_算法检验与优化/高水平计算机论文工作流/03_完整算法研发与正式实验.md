# ③ 完整算法研发与正式实验

**负责人**：Codex/WorkBuddy 主责；ChatGPT 仅在科学变更/证据门禁介入；你授权。

**阶段参考**：Superpowers `[原生调用]`；Autoresearch `[方法借鉴]`。仅匹配当前任务加载相应 Skill。

## 03-A｜一次性综合研发任务合同

**触发**：必做：02-D 已批准 GO  
**执行者**：ChatGPT 制定科研边界 → Codex 完成技术计划  
**Skill**：SP writing-plans / executing-plans `[原生调用]`

```text
输入：已批准研究合同、真实 repo 与上一阶段原始证据、授权预算。
目标：指定**一项可独立验收的中等偏大研发任务**，不要分派每个文件一次对话。
ChatGPT 明确要证明的科学改进及指标门槛/资源冻结/停止条件；Codex 只读取相关代码与差量，检查接口、数据与权限后自主规划和实现必要模块、测试、修复；在能独立验收的科学边界提交结果。
交付：代码/commit、受影响测试与指标的真实证据、RUNS.tsv 增量及 7 行简报。
停止：本次任务验收、关键失败或授权触顶；不能将“代码写完”解释为论文贡献已证实。
```

## 03-B｜正式比较合同冻结

**触发**：必做：正式宣称收益前，至多一次/重大变更需重建  
**执行者**：ChatGPT 定义科学合同 → Codex 校验真实实现  
**Skill**：AR 固定评估 `[方法借鉴]`；SP verification `[原生调用]`

```text
在正式优化/报告收益前：写明主张、主指标与统计单位、数据组别划分、最强基线、负对照、调参规则、预定 seeds/预算、确认性 test 和数据/代码版本指纹。
Codex 核实代码确实实现这些约束并执行必要小测试。改指标、评估脚本或样本规则需要显式版本化；改变后旧结果标探索性/无效，不允许假装没有变更。
交付：STATE.md 指向冻结的 protocol 文件/版本与实现核查证据。
停止：必要协议已冻结并获授权，不在此阶段跑大规模正式实验。
```

## 03-C｜可测试的算法实现与根因修复

**触发**：必做：算法相关功能尚未可靠实现  
**执行者**：Codex/WorkBuddy  
**Skill**：SP test-driven-development / systematic-debugging / verification `[原生调用]`

```text
只处理本科学任务所需的模块：先写关键行为/协议不变量的失败测试或最小复现，再实现/修复，运行相关测试及必要集成验证。
对于非预期差异先确定数据、数学、实现或评价的根因，修复后列出历史 run 是否受影响；保留本地现有仓库配置，不做无关大重构。
交付：代码变更、最小测试命令与运行证据、受影响 run_id。
停止：本任务功能与接口可靠或科学前提/权限阻断。
```

## 03-D｜固定预算内的算法探索优化

**触发**：必做：已具备可信评价和可运行基线  
**执行者**：Codex/WorkBuddy  
**Skill**：Autoresearch `[方法借鉴]`；SP verification `[原生调用]`

```text
在已有 GPU/时间授权范围内围绕**一个明确科学改进机制**探索，不把 AR 的 `LOOP FOREVER` 当成命令。
每次变更记录：可证伪的改进假设、commit、训练数据/划分、seed、预算、主指标与机制/负对照；在固定开发验证集上做 KEEP / DISCARD / INVALID 判断，保留失败记录。优先低复杂度、解释清楚的改进，避免只刷最佳 seed。
同类尝试无有效科学增益时，不为用完剩余预算而继续；优先判断评价偏差和强基线。
交付：RUNS.tsv 与最佳可复现候选、科学贡献增量、下一关键实验。
停止：预算、明确证据、核心反例或授权边界触发时立即停止。
```

## 03-E｜科学异常/重复失败专项分支

**触发**：条件：失败复现、性能反常、协议失效、无增益  
**执行者**：Codex 定位 → ChatGPT 科研决策  
**Skill**：SP systematic-debugging + SPS Problem Inversion

```text
Codex：复现最小异常，标记影响的 run/claim，按工程错误、数据/协议错误、科学机制无增益区分；执行最小必要修复与定向回归，若科学证据失效必须保留 INVALID 记录。
ChatGPT：只依据原始证据判断**修复后是否有机会增加中心论文贡献**；若是，给一条有界下一任务；若否，建议 PIVOT/STOP/HOLD。
交付：根因 + 受影响结果 + 一条建议；停止于根因已明确或需要用户方向/预算决策，禁止自动重写算法。
```

## 03-F｜正式确认性实验与贡献证据

**触发**：必做：探索阶段达到候选门槛；用户批准正式资源  
**执行者**：ChatGPT 定义最少必要证据 → Codex 正式执行  
**Skill**：SP verification `[原生调用]`；AR 固定评估 `[方法借鉴]`

```text
先指定论文中心主张（通常1–3条），分别确定合法的外部对照、真实统计单位、效应和不确定性、关键消融/泛化，以及既定未接触确认性 test。
Codex 严格运行授权冻结协议，保存每次尝试、原始预测、代码/数据身份、统计脚本和失败情况；不得挑 seed、改剔除规则、重复看 test 后调参。
将 claim → 真实 baseline/实验 → 效应与 CI → 适用范围 → 原始文件路径记入 CLAIMS.md；不支持的降级或剔除。
交付：正式证据矩阵和运行索引。
停止：关键确认性证据齐备或科学/资源阻断，不能以润色图片代替缺少的实验。
```
