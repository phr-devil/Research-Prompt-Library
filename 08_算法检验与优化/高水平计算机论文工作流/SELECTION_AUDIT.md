# 选题证据校准：历史风险情境与保护性正例（按需参考）

> **不是新关卡、也不属于每次F1–F4的必读文件。** 本文检查`IDEA_FUNNEL.md`的推荐逻辑，不评价模型真实运行成功率。历史项目的初次选题完整时点资料不齐；下述为**从现存历史记录抽取的“若当时已知这些信息”情境**，一律标`RETROSPECTIVE_UNVERIFIED`。不得偷用后来负结果声称流程当时能够预见失败。若有当时的原始时间戳/Run，应以它们重建严格的时点样本；不编造SHA、原始记录或未见成绩。

## 情境卡：只使用题中给出的已知信息判断

| 编号 | 选题时假定可获得的信息（不含后续结果） | 合理的F4输出与首个关键核查 |
|---|---|---|
| **A1 REALDISP** | IMU重戴偏移真实存在；有HAR标签，但真实各IMU旋转参数是否有独立真值尚不明确；最小熵校准机制未验证 | `EXPLORE / FRONTIER`；先问物理干预单位及已知旋转正控，不能因存在偏移就`RECOMMEND`在线校准，未知不是直接`NOT_READY` |
| **A2 RASS** | 异常检测强基线可运行，但“哪个检测器在当前来源更好”的决策前预测信号没有独立验证；已有动态选择文献 | `EXPLORE / FRONTIER`；最小来源级风险排序探针+固定/简单策略与测试标签隔离 |
| **A3 SafeSelect** | 与MetaOD/MetaEns等近邻方法存在显著重合；候选独立机制差额尚未从原文/代码核实 | `EXPLORE`或`NOT_READY`须取决于**具名机制实证**；不能仅因相同任务或模型名就断言`COVERED`，也不能包装成正式推荐 |
| **A4 ContactWorld** | 核心科学Claim必须依赖真实仿真闭环；经官方支持矩阵证实当前唯一平台不兼容，且无法切换系统/获得替代 | 对原闭环Claim为`NOT_READY / EXTERNAL_DEPENDENCY`；可建议不同离线Claim，不将平台阻断解释为算法理论失败 |
| **A5 OpenPack** | 四IMU相对一IMU在少量VAL受试者上有初步正增益；动态门控的合法决策前可预测性尚未证实 | **保留H1局部正发现**；动态激活Claim为`EXPLORE`，不自动`RECOMMEND`动态策略，也不因未知H2而判整个传感器研究失败 |
| **A6 CAR-IMU** | 信号重建可实现，但对姿态JPE的最简单零填补/保持原样输入参照尚无公平同协议比较 | 修复性能增益为`EXPLORE`；优先定义任务JPE和identity/last-valid原始参照，再批准训练 |
| **P1 保护性正例** | 独立真值、合法划分、可核强基线的重复失效及具名近邻增量都有出处；关键依赖可得；方法机制未实测但有物理/理论依据与明确的最廉价反证 | 允许**有条件`RECOMMEND`**，明确尚缺实验效果；不可因未跑过新模型而一律否决，也不得给“高录用概率” |
| **P2 保护性正例** | 具名近邻仅共享数据集/Backbone，候选有独立可证伪的新科学问题和合法评价；增益尚待测 | `OVERLAP`不等于`COVERED`；可为`RECOMMEND`或`EXPLORE`，取决于剩余证据，而非是否全部原创 |
| **P3 保护性正例** | 新机制没有既往实测，但理论问题重要、可证伪且低成本；真值和强基线合理，关键机制前提未知 | 至少保持`EXPLORE / FRONTIER`选项；不能因为历史失败多而全部`NOT_READY` |

## 成功路线保护性回溯（不等于历史预测准确率）

**SAFE-Gait / APACE（保护性案例）**：原始意向只是“鞋垫能否泛化到不同人/硬件”，当时未证明复杂主动校准策略能胜出。**初选阶段**应允许EXPLORE和受限MVP，而不是要求先证明论文完整贡献。之后APACE多步/单步/选择性无标签校准被各自有效Run否定时，应**DISCARD对应策略**，不把鞋垫研究整体STOP；可从确实存在的个体残差提出“一次监督校准后残差迁移”的不同Claim，按重大改题由用户选择并新授权。最终WearGait及GAITRite的部分结果是**事后成功路径证据**，不能拿来冒充当时初选已知事实；GAITRite并非全面稳健胜出或权重直接跨硬件迁移。

**对照边界案例**：ContactWorld关键闭环平台经证实不可替代时，仍阻断该闭环Claim/动作；REALDISP单人负烟测先修已知物理设定/BN错误，既不PROJECT STOP，也不自动新增昂贵训练；RASS如合法决策前信号缺失，停止原在线选择机制，但允许不同预测的新命题有界探索。两类错误——**过早全项目退出**与**没有新信息的无限延长**——都必须被识别。

## 对照时不允许出现的三类错误

1. **泄漏**：把后来发现的F1下降、失败机制、H2/H3后验结果写入当时输入。情境A1–A6的标签仅检验**给定证据下推荐是否越界**，并非历史预测命中率。
2. **过严筛选**：因为没有新模型的实验PASS、方法与文献部分重合，或历史项目总体STOP，就拒绝P1/P2/P3，抹除A5的已知正证据。
3. **伪验证**：静态存在关键词、Agent自评、只生成离线调用计划都不等于成功；真实A/B必须先冻结独立未见案例，实际运行模型后盲评，报告严重误推荐率、错误排除率、人工核证成本、真实Token和检索来源，不能只报淘汰了多少失败课题。

**下一次真正评估**：取至少一组有时间戳的旧候选初始材料和一组未用于修改规则的全新候选，锁同模型、工具、预算、输入证据和人工盲评标准；同时检查“致命漏判”和“保护性误杀”。如不能重建时点，明确`NOT_MEASURED`，绝不写提升成功率。
