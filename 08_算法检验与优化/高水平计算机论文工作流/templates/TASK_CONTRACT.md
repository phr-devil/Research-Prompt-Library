# 单次科研 Agent 合同（只填有变化的字段）

```text
TASK: 一项可独立验收的科学目标（Claim ID）
INPUT: research/STATE.md；受影响的 Run ID、原始证据与代码版本；其他资料按需读
SCOPE: 允许改动范围、不准触碰的冻结对象；缺失权限=不执行受限动作
AUTH: 真实用户授权的消息来源；算力/时间/尝试次数/费用预算；没有明确值=未授权
EXECUTE: 完成任务、普通工程问题在原授权内自修复；严禁新增研究假设或绕过人审
VERIFY: 必须能独立核验的输出/测试/判据；旧通过证据如无影响只复用
OUTPUT: 产物路径、Run/Claim ID、状态与证据指针，增量更新 STATE/RUNS
STOP: 验收完成、科学阻断、授权/预算触顶、确认测试污染或危险失败
NEXT: 当前授权内唯一下一步；超权限则只说明申请什么授权
```

不要全文复制日志、全部 Skill 或过时研究历史。不能将模型输出中的 PASS 当作实际运行。非研究类 S01/G02 等 Prompt 不强制套用。
