# 单次科研 Agent 合同（只填有变化的字段）

```text
TASK: 一项可独立验收的科学目标（Claim ID）
INPUT: research/STATE.md；受影响的 Run ID、原始证据与代码版本；其他资料按需读
SCOPE: 允许改动范围、不准触碰的冻结对象；缺失权限=不执行受限动作
AUTH: 真实用户授权的消息来源；算力/时间/尝试次数/费用预算；没有明确值=未授权
EVENT: 依据当前真实状态选一项ROUTES.json事件，读取其对应playbook（不是依次遍历全部）
EXECUTE: 在已授权范围内连续完成相关实现/受影响测试/有界实验；普通Bug自主修复；科学主张实质转变要用户确认
DISCRIMINATION: 本轮竞争解释A/B与分别可观察的结果签名；若只是工程修复则写待验证的不变量
METHOD: 涉及算法模块时写明确 Input/Output、机制、Loss、推理信息流、复用/新增/不采用组件
BASELINE: 涉及结果比较时写同目标/时域/信息/评估的简单与最近邻强基线，或无法复现原因
STATISTICS: 涉及效果宣称时写独立单位、主要比较、重要效应/不确定性、探索/确认数据隔离
VERIFY: 必须能独立核验的输出/测试/判据；已知行为用真实测试与输出，未知科研价值用真实对照；旧通过证据如无影响只复用
OUTPUT: 产物路径、Run/Claim ID、状态与证据指针，增量更新 STATE/RUNS
STOP: 验收完成、科学阻断、授权/预算触顶、确认测试污染或危险失败
NEXT: 当前授权内唯一下一步；超权限则只说明申请什么授权
```

不要全文复制日志、全部 Skill 或过时研究历史。不能将模型输出中的 PASS 当作实际运行。非研究类 S01/G02 等 Prompt 不强制套用。
