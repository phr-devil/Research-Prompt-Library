# 科研探索续投与终止决策（第08章）

> **低门槛探索、中门槛续投、高门槛论文确认。** 仅在选题、负Pilot、科研分叉或资源追加时按需读取；**不是新审批阶段**。优先基于最新真实Run、协议与用户授权作决定，不凭空估计发表概率；不能将工程FAIL或某机制FAIL扩写为PROJECT级科研失败。

## 1. 三层要求：不要用论文标准限制早期探索

| 当下目标 | 准入/继续依据 | 此时不必已经证明 |
|---|---|---|
| **EXPLORE/原型探索** | 有合理理论/物理/文献动机的可证伪机会；合法低成本探索路径；无已证实不可替代致命阻断；用户已选题且动作有真实授权。可先用代理诊断但不得冒充正式证据 | 新网络超过强基线、多seed显著、全面文献覆盖、外部确认、可投稿 |
| **CONTINUE/追加研发** | 有新发现、关键未解解释或必要实验能力缺口；下一动作能减少重要不确定性、解除可修复阻断或为后续关键验证创造能力，成本合理且不超授权；新科学机制分支才需不同预测 | 每一次必须性能提升、模型一定能发表、固定次数/固定GPU小时门槛 |
| **CONFIRM/正式论文主张** | 合法独立真值/证明义务、充分调优的强基线、公平统计、冻结未污染确认集、具名近邻独立贡献及所需真实授权 | 不能以探索性收益、工程通过、代理指标代替 |

关键依赖**已证实不可替代且阻断当前动作**→只阻断该动作；仅未知→保留EXPLORE/UNKNOWN并查最廉价关键事实，不能假称已PASS。明确禁训练时CPU Ridge拟合、tiny-set训练和GPU训练均不执行；付费、正式确认、投稿与外传单独核授权。

### 负结果先判断“测到了什么”，不要把欠验证当反证

**宽松只适用于早期EXPLORE/有界续投**：可有未实测机制、粗预算、1–2项近邻、探索性代理/自监督证据；一次先核最危险的一项，不把正控、可辨识性、强基线三项机械全设为准入关卡。CONFIRM的独立可信评价、充分强基线、统计与未污染测试集要求不变。

**首次未见增益 ≠ 证明机制无效**。先按当前Claim检查最可能改变结论的一项：评价/泄漏/标签合法性、物理正控或实现一致性、收敛与合理nuisance调参、主任务指标与最小有意义效应（SESOI）及独立单位的检出能力。按需核验，**不要求把这些全部列为前置门禁**。

- 证据有Bug、泄漏或目标不符→`INVALID + REPAIR`受影响Run；不能将失效指标用于止损或“救活”论文。
- 合法但欠训练、统计区间太宽、正控/比较不能区分解释→`INCONCLUSIVE`；若有**廉价且有判别力**的下一步，允许CONTINUE或REPAIR；若补证成本过高则HOLD，**不是把机制写为科学REFUTED**。
- 任务指标与简单强基线**在公平且足以识别关心效应的条件下**确有负结果→`DISCARD`当前Run/机制；若只是无显著改善、不能排除有意义收益，仍为INCONCLUSIVE。之后先看是否有新机制假设，不能因一个网络输掉就扩大至整个项目。
- 禁止两种偏差：用合成正控代替真实可部署收益；以及用“永远可能欠训练/统计效力不足”要求无界重跑。每次补证都需估计其可检出性、结果解释和投入成本。

## 2. 负结果后的四种投入决定（与科研证据状态分账）

| 决定 | 什么时候选 | 应执行的动作 |
|---|---|---|
| **CONTINUE** | 有可验证的机制信号或低成本实验能够区分竞争解释 | 在**已经批准**的范围内连续完成有关实验；记录全部结果、恢复点，保护评价器 |
| **REPAIR** | 数据、真值映射、物理单位、评价、实现、容量或训练不充分，使该Run结论不可信；或需要取得可信的测量/比较能力 | 隔离受影响结果，定位根因→最小修复→针对性回归。**普通必要Bug修复不必每次证明新论文贡献** |
| **PIVOT** | 当前机制被否定，但原数据/残差/反例支持**不再依赖失败前提**的另一个可证伪命题 | 冻结旧Run和有效资产，提出至多少量具有不同结果预测的替代科学解释；**实质改题/第09章选题仍由用户新消息选择** |
| **HOLD / STOP** | 暂缺资源→HOLD并写恢复条件；无值得检验的新假设、实验正反都不影响决策、重复调参没有信息增量或成本失衡→建议STOP | 明确仅终止RUN/MECHANISM/CLAIM还是PROJECT。**项目级HOLD/STOP由用户决定**，除非用户已经明确指示 |

科研证据结果仍单独标 **KEEP / DISCARD / INCONCLUSIVE / INVALID**；投资决定不等于科学证伪。一次负Pilot、缺显著性、部分文献重合不能自动PROJECT STOP；正式确认泄漏/无权训练则无论自由探索程度均阻断受影响操作。恢复科研真实性所必需的修复不受“短期性能价值”否定。

## 3. 唯一续投检查：下一项实验的决策信息价值

按现有STATE/RUNS简记三问即可，不另填表：

1. **学到了什么？** 可信原始Run支持/否定了哪个范围，还是代码或评价错误？保留观察与尚未排除解释。
2. **再做什么会减少关键不确定性或得到必要实验能力？** 科学机制分支预写A/B解释和不同结果签名；标定/同步/修复/容量诊断只需写能力验收与下一项有效实验，不伪造A/B假说。探索实验**无需立刻改变GO/STOP**，只要能排除解释、识别残差规律或解决实现疑点；若任何合理结果都不改变理解或下一动作，就停此分支，先考虑PIVOT/HOLD。
3. **相比替代实验值不值？** 先考虑低成本真值核查、物理正控、强简单基线及定向修复；追加成本越大，对独立信息/论文价值越严格。空闲GPU和沉没成本都不是续投理由。

**防无限续命：跨分支累计核相同失败前提。** 换Backbone、Loss、项目名、数据切片或Prompt不能自动刷新已失败的科学假设与预算；检查它是否仍依赖同一不可观测的部署信号、同一缺失真值或同一平台。如果仍依赖，先用不同预测的廉价证据解除原阻断，否则停止这些**共享前提的分支**。反之，确有新可观测现象、不同机制与合法评价时可PIVOT，不能因为旧项目多次STOP而误杀；**重大改题继续由用户选择**。比较从最初立项以来的总GPU、Token、人工与时间成本及其他候选的机会成本，不用固定失败次数；HOLD写明新证据/资源的重启触发，STOP注明被关闭的Claim范围。见[保护性与止损案例](SELECTION_AUDIT.md)。

**Token/总成本约束**：复用原始Run和已核证据，已授权范围内连续完成有关联任务，不重复全文检索、全量重检或例行多Agent审查；只输出必要新增证据。总Token+GPU+人工成本优化不允许删除关键科学核验或用户批准。

**最短输出（增量写原记录即可）**：原Run及证据级别 / DECISION_SCOPE / 新发现 / 下一实验正反两种决策 / COST与真实AUTH / CONTINUE、REPAIR、PIVOT或HOLD/STOP / 恢复条件。未知写UNKNOWN；不按固定失败次数自动判PROJECT死刑，不无限循环调参。正式Confirm要求独立确认数据，不得反复选用原测试集。

## 4. 从开源项目借鉴的最小机制

- [AIDE](https://github.com/wecoai/aideml)：保留有父子关系的实验分支及最佳有效Run；**不强制装树搜索**。
- [RD-Agent](https://github.com/microsoft/RD-Agent)：失败反馈应生成不同预测的研究假设；**不要等价换名字或Backbone**。
- [autoresearch](https://github.com/karpathy/autoresearch/blob/master/program.md)：固定共同评价器、记录尝试、保留/回退；**不采纳无限循环或仅凭单一训练指标评定科研价值**。
- [Google Deep Learning Tuning Playbook](https://github.com/google-research/tuning_playbook)：探索期优先积累对数据/训练机制的认识，性能利用阶段再集中追逐主指标；区分scientific/nuisance/fixed超参数，不能以欠调优负结果草率淘汰机制。
- [AI-Scientist-v2](https://github.com/SakanaAI/AI-Scientist-v2)及[Ray Tune/ASHA](https://docs.ray.io/en/latest/tune/api/schedulers.html)：按实测信息逐步分配资源，而非一开始证明所有机制；**ASHA早期Loss排名仅适于可比训练任务，不足以推断假设被科学证伪**。

**回溯案例，不是事前预测**：

- [APACE→SAFE-Gait](https://github.com/phr-devil/SAFE-Gait)：预决策无标签主动校准机制失败后，保留可观察的个体校准残差，转向“一次监督校准后残差迁移”——**实质PIVOT**；跨硬件复现是部分方向有效的下游校准规律，不是权重零样本直迁。
- ContactWorld：闭环平台缺可执行证据时先最小平台核验；若确证不可替代阻断，仅停该闭环动作，离线新Claim另评。
- RASS/IMU门控：若缺合法决策前信号，停止当前在线策略，不凭“还有希望”无限改门控；合法固定配置/新表征是否有独立价值另看证据。
