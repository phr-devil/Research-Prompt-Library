# ② 最小科学验证与方向决策

**负责人**：ChatGPT 设计；Codex/WorkBuddy 访问真实仓库、执行；你批准。

**阶段参考**：SPS `[阅读参考]` + SP 的 TDD/verification `[原生调用（已安装时）]`。仅匹配当前任务加载相应 Skill。

## 02-A｜风险排序与最小判别实验

**触发**：必做：①阶段获批准  
**执行者**：ChatGPT  
**Skill**：SPS `[阅读参考]`；AI-Scientist-v2 `[方法借鉴]`

```text
目标：选择**下一次实验最有可能改变 GO/PIVOT/STOP 判断**的问题，而不是做缩小版完整网络。
执行：①排序最多2个致命假设（数据能否独立标注、机制能否产生可区分信号、基线是否已达到上限）；②写出如果 H 为真/假，各种对照预期如何变化；③定义样本独立单位、最小样本覆盖、效应方向、强基线、必要破坏性负对照与有效性检查；④估算计算开销及最小合理重复度，样本不足时不作显著性承诺。
交付：最小实验合同：H / 数据 / 对照 / 指标 / 统计单位 / 混杂 / 停止条件 / 授权需求。
停止：实验足够区分关键解释即可；不要求完整架构、不擅自设置不可获得的样本量。
```

## 02-B｜真实数据与评价可用性审计

**触发**：必做：任何有数据的最小实验前  
**执行者**：Codex/WorkBuddy  
**Skill**：SP test-driven-development + verification-before-completion `[原生调用]`

```text
目标：证明本轮实验数据与评价接口**可用于回答问题**。
只检查必要范围：数据许可和清单、标签独立性、采样率/时序/单位、数据缺失、分组划分、train-only 归一化、测试集可用性和评估函数。为潜在泄漏和关键单位/时序不变量补最少量可运行测试。
若标签本质上是输入的代理变量，标明“只能验证代理任务”；若已有 test 污染，标明历史结果级别。
交付：PASS/BLOCKED 与可追溯证据、可运行最小 baseline 入口；只写受影响的差量记录。
停止：数据可信或确定阻断；不要提前训练大模型、重构不相关代码。
```

## 02-C｜执行最小真实实验

**触发**：必做：02-B PASS且资源已获授权  
**执行者**：Codex/WorkBuddy  
**Skill**：SP verification-before-completion `[原生调用]`; Autoresearch 固定评价思想 `[方法借鉴]`

```text
目标：只回答预先定义的科学判别问题。
按合同固定数据分组、指标、预算和比较条件，运行简单但合理的强基线、假设候选和关键负对照；保存有效样本数、原始预测、配置/版本、所有 seed 与失败运行；公平匹配可用模态、时间视野和训练数据。
若技术 bug 影响比较，先修并重新验证；若科学前提明显不成立或评价口径要改变，停止并报告；不可将验证集反复试验所得称为独立确认结果。
交付：RUNS.tsv 增量与简短结果：支持/反证/无效/不充分，各有原始路径。
停止：合同实验完成、预算触顶或重大阻断；不自动增加模型规模或进入阶段③。
```

## 02-D｜GO / PIVOT / STOP / HOLD 门禁

**触发**：必做：收到有效最小结果  
**执行者**：ChatGPT 评估 → 你批准  
**Skill**：SPS Decision Tree `[阅读参考]`

```text
按顺序判断：①数据和比较是否有效；②核心科学前提是否有可信的初步信号；③最强既有方法是否留下独立贡献空间；④下一步投入能否产生关键论文证据。
只给一个建议：GO（初步值得继续）、PIVOT（原主张受阻但有新的独立命题）、STOP（可信反证且替代价值不足）、HOLD（关键数据或证据不足）。
每项决策附2–4条证据、反对证据、最有信息量的下一实验/授权条件；不因既有投入或假设框架复杂而偏向 GO。
交付：STATE.md 决策建议；**等待你批准**。
停止：不替用户授权新 GPU 预算、不写下一阶段大规模开发 Prompt，除非用户已批准 GO。
```

## 02-E｜效果消失/基线远强时的定向诊断

**触发**：条件：负对照≈真值、baseline更强、结果反常  
**执行者**：ChatGPT 设计 → Codex 定向实验  
**Skill**：SP systematic-debugging + SPS Problem Inversion

```text
触发：[真实观察、原始 run_id]。不要先调整架构。
给出最多3个竞争解释：数据/评价伪影、科学假设不成立、当前模型能力不足。为每个解释设计可以产生不同预测的**一个最短诊断**（可合并时合并）；Codex 在原授权内只运行可区分解释的测试。
交付：根因证据 + 受影响旧结论 + 是否仍值得继续的判断。
停止：区分主要机制即止；不能借诊断之名重新启动无界训练。
```
