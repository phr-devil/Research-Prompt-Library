# 第十章｜AI 最短入口

**只在用户明确选择第十章/问题—数据驱动开放研究时进入**；第08章机制驱动与第09章失败挽救保持原样，不自动迁移。只读 [WORKFLOW.md](WORKFLOW.md)＋当前真实研究状态，按下一问题选择一份专题；一般不用一次加载整个目录。

- 用户只给研究方向、尚未选数据库：读 [DATA_DISCOVERY.md](DATA_DISCOVERY.md)，ChatGPT先只读核问题—数据组合；**用户选择组合不是批准训练**。
- 已有组合但数据未就绪：读 [DATA_DISCOVERY.md](DATA_DISCOVERY.md)，有真实授权才下载/安装，超大集可分片；封存确认集。
- 数据已可观察、具体任务未知：读 [TASK_EXPLORATION.md](TASK_EXPLORATION.md)，从开发数据现象/物理/近邻产生有依据的候选任务。
- 已有任务、代码或 Pilot：读 [EXPERIMENT_LOOP.md](EXPERIMENT_LOOP.md)，复用现有证据，在授权预算内探索/修复；负Pilot不自动项目级STOP。
- 已有稳定候选贡献、要论文确认：读 [CONFIRMATION.md](CONFIRMATION.md)，公平基线、独立确认、具名近邻与统计严格核查。

**输出**：实际新证据、可恢复路径、下一项最有信息量的任务及授权缺口；无执行工具标 NOT_RUN，证据不全标 UNKNOWN，禁止编造结果或自动承诺发表。
