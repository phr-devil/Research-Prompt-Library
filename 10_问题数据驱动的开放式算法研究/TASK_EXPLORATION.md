# 活动 03/05｜发现具体任务、维护机会、收敛科学 Claim

**本文件只回答研究什么与为什么有价值**。实验怎么做交 [EXPERIMENT_LOOP.md](EXPERIMENT_LOOP.md)，RUN/机制、Task、Area-Data 级续投与止损由 [WORKFLOW.md](WORKFLOW.md) 唯一决定；不要在本文件重建审核关卡。

## 1. 系统化任务机会扫描（已有一个可信机会就开展实证）

| 来源 | 寻找什么 | 最小可信判别 |
|---|---|---|
| **真实失效/残差** | 简单基线在物理状态、时间、设备、受试者的何种条件下失效 | 合法开发数据中的配对预测/独立 group 复核 |
| **科学/物理先验** | 漂移、摩擦、接触、时间因果、信号几何能否推出可证伪规律 | 物理分析或获授权的最简正控 |
| **应用能力缺口** | 延迟、标定量、能耗、传感器稀疏或部署前可见信息约束 | 同信息同成本的简单/固定策略 |
| **跨域与异质性** | 人/设备/环境变化是否出现稳定差异 | 合法 group 划分与简单校准 |
| **具名近邻未解决部分** | 既有任务/机制的条件、成本、真值或独立验证缺口 | 定向核最近论文与实现 |

按当前数据和问题只选 **1–2 类**，不扫描全表/全数据切片；发现一个合理可证伪机会即可进入实验。真实开发证据标 `OBSERVED`，物理或文献预测标 `HYPOTHESIZED`，代理真值标 `PROXY_ONLY`。未跑强基线写 `BASELINE_PENDING`，不因未知可学性就判失败；已观察的相关性不能直接写科学发现。

## 2. 最小 TASK_CARD 与当前选择

每项最多八要素，可复用现有文件：`TASK_ID/ORIGIN`｜`SCIENTIFIC_QUESTION`｜`INPUT_TARGET`（部署可见输入、独立真值/证明义务、组）｜`TESTABLE_DIFFERENCE`（只有机制归因才必须要求竞争 A/B 预测）｜`BASELINE`｜`VALUE`（近邻之外可能新增的知识或真实能力）｜`MINIMUM_PROBE`｜`COST_RISK`。

**成熟度与价值分账**：`VALUE_UNVERIFIED`≠低价值；`BASELINE_PENDING`≠不可探索；“能跑通”≠“有独立论文贡献”。优先比较：评价/真值可达性、实际科学需求、下一廉价探针的信息价值、总资源成本和已有资产。跨不同任务不可直接按 F1/AUROC 排名，也不虚构发表概率。

只需保留 `PRIMARY_TASK` 和至多一项有**不同失败前提**的 `RESERVE_TASK`（允许为空），明确 `NEXT_DISCRIMINATING_PROBE`；不能要求凑满三个新算法或先有显著增益。

## 3. 主任务与机会储备：允许主动调整，不无限重新选题

出现真实新现象、具名近邻新证据、有效负结果或明显不同的科研机会时，再比较主/备选任务的独立价值、可学性证据、评价路径、最小下一实验与累计成本；普通训练调参不触发全量选题。

- 换 Loss/Backbone 或重用同一已否定的真值/可辨识性前提，不构成**不同失败前提**。新任务应有实质不同的输入、干预、目标或可反驳解释。
- 同一批准的核心问题—数据范围内可在真实授权内探索其他任务；实质改变用户选定问题、数据库或资源时由用户决定。`Run/机制` 失败不能直接扩写成 `Task`、`Area-Data` 失败。
- 保存 `task_id → selection_history → protocol_id → eligible_holdout`：开发组切片、任务、指标及失败实验均可追溯。改变标签、组别、输入或时间关系后，旧封存组未必适配；不能读测试集来择题，也不能重划分已污染数据制造独立确认。

## 4. 从任务到科学 Claim 的适时收敛

初期只核最相关 1–2 项具名近邻；出现可信增量、考虑昂贵机制实验或准备确定主 Claim 时，定向核官方论文/实现的真实覆盖范围；未核到原文标 `NEIGHBOR_UNVERIFIED`，不靠印象宣称已覆盖或完全新颖。

`CLAIM_CANDIDATE` 必须说明：①一句可被反驳的新增科学知识/能力；②有效 Run/开发组真实现象及证据路径；③最强简单替代与直接近邻的差额；④适配且未污染的确认路径；⑤可能需要收窄的主张。只有代理分数/工程复现时写 `NO_INDEPENDENT_CLAIM`，有独立机会但仍缺证写 `CLAIM_WITH_GAPS`。详细正式证据只在 [CONFIRMATION.md](CONFIRMATION.md) 验证。

**止损只按证据作用范围**：有新的、可负担的观察/能力/机制差异可继续；没有值得运行的下一探针可 HOLD 该分支而非宣布全项目被证伪。不要在本文件另设 Run/机制、Task、Area-Data 的第二套门槛。
