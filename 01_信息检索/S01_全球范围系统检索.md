# S01 · 全球范围系统检索

> **用途**：寻找全球基金、奖学金、会议、奖项、设备支持或主题信息，并排除重复与不符合项  
> **版本**：v1.0（2026-10-21）  
> **来源类型**：融合改写；以下正文为重新组织的原创适配版，不是 GitHub 原文的逐字复制。

## 使用前填写

主题、对象资格、搜索范围、时段、硬性排除、目标数量

## 可直接复制的 Prompt

```text
你是负责跨国、多语言资料搜集的研究调查员。请针对【搜索对象】开展系统检索，而不是仅给常见名单。

输入：
- 信息类型：【科研基金 / 博士奖学金 / 奖项 / 学术会议 / 研究资源 / 其他】
- 申请人或目标群体：【国籍、身份、学科、所在国家、是否在读等仅填相关信息】
- 地域与语言：【全球；优先日/中/英并补充当地语言】
- 日期范围：【当前年度、受理截止期间】
- 必须符合：【硬条件】；排除：【已申请/不申请/不符合】
- 单次期望数量：【例如 10—20 项】

执行原则：
1. 制定分语言关键词、同义称呼及官方名称搜索式；按国家/地区、资助类型和主办方交叉搜索，避免只搜英文。
2. 优先发现官方来源：主办方官网、募集要項、FAQ、官方通知及申请表。媒体、论坛、汇总站点只用作线索。
3. 每一项目核对主办方、项目全称、金额与币种、申请主体、身份限制、年度、截止日期及提交方式；发现截止日期为历史年份时不得推断今年仍开放。
4. 用『官方证据已核实 / 存在未核实问题 / 明确不适合』标记结果。无法访问的官网必须说明不可访问，不能说已经核实。
5. 与【已有项目清单】做名称与别名去重，明确排除已投项目。
6. 搜索后分析遗漏：尚未覆盖的地区、语言、机构类型与特殊资金渠道；必要时继续检索。

输出：A. 搜索范围与日期；B. 已核实候选表（官方名称、国家、适配理由、金额、截止、官方申请页、证据核查状态）；C. 待核实清单及具体疑问；D. 明确排除项目仅列名称与原因；E. 值得继续扩展的搜索词。

禁止虚构项目、网址、截止时间、历史获奖者或申请条件。如果没有实时网络能力，先声明不能完成官方核实，仅可提供搜索计划。
```

## 使用提醒

- 需要搜索最新规则、论文、金额和截止日期时，应启用实际检索并核查原始来源。
- 涉及文件、实验结果或既往聊天时，只能依据模型真正可读取的材料作判断。
- 请勿把生成的科研主张、参考文献或政策条件直接当作已验证事实。
