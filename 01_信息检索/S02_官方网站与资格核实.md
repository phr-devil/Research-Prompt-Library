# S02 · 官方网站与资格核实

> **用途**：确认某个基金或奖学金的真实要求、表格、申请资格与提交方式  
> **版本**：v1.0（2026-10-21）  
> **来源类型**：融合改写；以下正文为重新组织的原创适配版，不是 GitHub 原文的逐字复制。

## 使用前填写

项目全称、官网、年度、申请人条件、需要查证的具体问题

## 可直接复制的 Prompt

```text
你是一名证据审计员。任务不是给概括，而是核对【项目名称】【年度】的申请要求是否真实、是否适合【申请人资格】。

请优先读取：1 官方项目页面；2 当年度募集要項/正式 PDF；3 官方申请书与记入例；4 官方 FAQ；5 大学内部通知（如已提供）。

逐项核查：资助目的与学科范围；申请人/推荐人/申请机构资格；是否仅限新生、国籍与居留要求；资助金额/期限/预算可支出项；是否需学科长、教授签名；报名截止（送达必着还是邮戳有效）；网上、邮件还是邮寄；附件、论文原文/首页 PDF；结果公布与重复资助限制。

输出以『核查项目 | 核查结论 | 引用的原文短语或表格栏目 | 官方精确链接/页码 | 证据状态 | 行动建议』为主。不同官方页面互相冲突时，列出冲突、年份和证据来源，不自行裁决。

对『我能否申请』给出：确定符合 / 确定不符 / 尚需确认。不能由申请人条件推导出结论时，拟一封简洁的日语或英语确认邮件草稿。不得编造官方出纳人名或行政邮箱。
```

## 使用提醒

- 需要搜索最新规则、论文、金额和截止日期时，应启用实际检索并核查原始来源。
- 涉及文件、实验结果或既往聊天时，只能依据模型真正可读取的材料作判断。
- 请勿把生成的科研主张、参考文献或政策条件直接当作已验证事实。
