# 10｜科研工作流状态校准提示词

> 适用于在 **ChatGPT 对话框** 中手动插入校准命令，辅助长期科研项目的上下文恢复、执行核查、关键门禁和科研路线复核。原有四种中途校准 Prompt **按需选一个**；另新增 **C10-E 新项目启动 Prompt**，供首次开题使用，不构成新科研阶段、定时任务、永久记忆或额外审批。PD-RW 权威规则仍在 [独立仓库](https://github.com/phr-devil/Problem-Data-Research-Workflow)；本章只提供可复制的调用指令，不重复维护规则。

## 使用选择

| 编号 | 类型 | 建议触发时机 | 核心作用 |
|---|---|---|---|
| C10-A | 状态恢复 | 新对话、长时中断、上下文压缩或怀疑混淆项目 | 找回项目、有效证据、授权和下一步 |
| C10-B | 执行校准 | 一轮重要研发完成后、发现规则遗漏或交付偏离 | 核适用规则是否被实际执行 |
| C10-C | 关键门禁 | SEALED/正式确认、重大科研决策、写稿、外传或付费前 | 核真实用户选择和操作授权 |
| C10-D | 科研价值复核（可选） | 连续无实质进展、出现重要负结果、主张价值不确定时 | 比较继续、补证、收窄或转向 |
| **C10-E** | **[全新科研项目启动（单独文件）](C10-E_全新科研项目启动.md)** | **新项目第一次启动时** | **填写研究方向、10类研发目标及资源配置；按 PD-RW H1–H10 执行作者选择与合法自主研发** |

**边界**：优先复用当前上下文、项目现有 `RESEARCH_RECORD.md`、`PAPER_BLUEPRINT.md`、STATE、真实 Run 与适用规则；**不凭模型自述替代原始文件和用户授权**。只有工具或连接实际可访问时才能声称已核对 GitHub 或本地文件；读不到就说明缺口。ChatGPT 中发送提示词**不会自动改变另一个正在运行的 Codex/WorkBuddy Agent**，需要将校准结果传递给其实际执行环境。避免固定每 N 轮机械执行或重复全库读取。

## C10-A｜状态恢复

适用：跨会话/中断恢复；也可在项目名称、数据集、阶段被混淆时使用。

**可直接复制的 Prompt**

```text
请依据 PD-RW 当前适用规则及本项目可访问的持久化文件恢复状态。核实项目身份、已确认的用户决策、有效与失败实验、证据与权限边界、尚未完成事项和下一合法行动。以原始 Run/协议及真实用户消息为准，优先复用已核信息；无法访问的内容标为未核实，不凭记忆编造，也不重复已完成工作。简要输出已恢复状态、关键缺口及下一步。
```

## C10-B｜执行校准

适用：重要任务交付后，或者发现规则被忽略、论文章节/研究记录遗漏更新时。

**可直接复制的 Prompt**

```text
请校准当前 PD-RW 工作流的实际执行情况。只核对本任务适用的规则与已有证据，检查阶段偏离、规则遗漏、错误结论、无效重复实验，以及 RESEARCH_RECORD/PAPER_BLUEPRINT 在重要变化后是否需要更新。指出可以验证的偏差，并在现有授权范围内自主修正；无实质问题就继续原任务。不新增审查阶段、文档或人工确认，仅报告偏差、证据、修正及下一步。
```

## C10-C｜关键门禁检查

适用：只有真正涉及受保护操作或重大作者决策时才插入，不用于普通 DEV 算法调参。

**可直接复制的 Prompt**

```text
请核查当前操作对应的 PD-RW 关键门禁：作者已选择的核心 Task/Claim、真实操作授权、SEALED/正式确认隔离、写作与绘图权限，以及任何付费、外传或投稿限制。以可核验的用户原消息与冻结协议为准，不以状态标记或 Agent 自评代替授权。已批准范围内的安全普通 DEV 开发无需逐次确认；只有关键权限或重大科研选择缺失时才暂停受影响操作并说明。此检查本身不授权新动作。
```

## C10-D｜科研价值与路线复核（可选）

适用：大量研发投入后结果无增量，或新的负结果动摇研究价值；不是每次实验后必须执行。

**可直接复制的 Prompt**

```text
请基于 PD-RW 和现有可信实验复核当前研究价值：核心科学问题、具名最近邻的真实差额、强基线、有效与负结果、证据缺口和 JCR Q2+ 投稿潜力。比较继续优化、补充证据、收窄主张或调整研究路线的实际收益与成本，推荐最有依据的一项及关键反证条件。优先复用已有 Run，不无故重训或重复检索；重大科研战略变更仍由作者决定。仅汇报判断依据、推荐和下一步。
```

## C10-E｜全新科研项目启动（独立文件）

**新项目使用专门模板**：[C10-E_全新科研项目启动.md](C10-E_全新科研项目启动.md)。包含使用者配置区（研究方向、快速发文/稳健发表/均衡发展/Q1/顶级突破等10种研发目标、贡献偏好、数据、算力、研究周期、其他限制）及依 PD-RW 最新规则执行 H1–H10 的完整 Prompt。只有第一部分需要填写；H6 核心 Task、H8 主 Claim 等重大科学选择仍由作者决定，H7 已授权安全 DEV 由 AI 自主。不与 C10-A 的旧项目恢复混用，也不新增工作流审批。首次启动时选 E；已有项目继续使用 A–D。

## 最简用法

- 新聊天或断点恢复：复制 **C10-A**。
- 发现执行偏离或完成重要一轮工作：复制 **C10-B**。
- 正式确认、SEALED、写稿或外传前：复制 **C10-C**。
- 科研长期没有价值增量：按需复制 **C10-D**。

**不要四条连发**，也不要因发送这些提示词就重开已确认任务或扩大任何权限。以上 Prompt 为本库针对 PD-RW 长期执行的原创整理；是否改善可靠性仍需真实中断恢复和任务对照验证，不声称已实测。
