# 10｜PD-RW-Agent 启动、恢复与校准提示词

> **用途**：供 WorkBuddy / Codex 等当前正在执行科研任务的 Agent 按需使用，也可用于 ChatGPT 外部只读复核。A–D 是既有项目的短指令；[C10-E](C10-E_全新科研项目启动.md) 用于新课题首次启动。**不新增科研阶段、审批或定时任务**，不要求四条连发。
>
> **权威分工**：[PD-RW](https://github.com/phr-devil/Problem-Data-Research-Workflow) 负责科研流程、原始证据与作者授权；[PD-RW-Agent](https://github.com/phr-devil/PD-RW-Agent) 的 Skill/Python/MCP 负责按需恢复、检索和辅助审计；本提示词库只负责触发当前任务，不复制规则，也不能给工具增加权限。以实际安装版本和可访问来源为准，不能凭 GitHub 最新版本假定本地已升级。

## 选择一个合适的入口

| 编号 | 何时使用 | 主要结果 |
| --- | --- | --- |
| **C10-A** 恢复与接续 | 新对话、中断、换项目或怀疑身份混淆 | 恢复真实状态并继续合法行动 |
| **C10-B** 执行偏差校准 | 已观察到重复实验、规则遗漏、异常结果或重要交付偏差 | 有证据的针对性修正 |
| **C10-C** 关键门禁 | 将执行 SEALED/独立确认、重大 Task/Claim 决策、付费、外传、图件、写稿或投稿 | 对受影响操作核真实授权 |
| **C10-D** 科研价值与经验复用 | 重要负结果、连续无增量、需要选择继续/收窄/转向 | 利用历史证据推荐最有信息价值的行动 |
| **[C10-E](C10-E_全新科研项目启动.md)** 全新项目启动 | 首次确定新研究方向、目标与资源 | 作者选择 → 合法项目登记 → Agent 接续 |

## 执行端边界（所有 Prompt 适用）

- **WorkBuddy/有本地权限的 Agent**：若当前确实加载了 `pd-rw-research` Skill、已连接 MCP 且项目映射允许，则按需**实际调用**工具；调用后继续完成已授权的普通 DEV 工作，不把审查变成新阶段。新项目未登记时不伪造 `project_id`。
- **ChatGPT 外部复核**：只能使用当前会话真实可访问的文件与连接；不能借发送本指令远程控制另一独立 WorkBuddy 会话，也不能声称使用了未连接的本地 MCP/运行了实验。需执行的修正应交给实际执行端。
- MCP 不可用时记录 `MCP_NOT_USED` 及原因**一次**，使用可访问的原始 PD-RW 文件与既有合法工具回退；不要重复连接探测、重建项目或虚构结果。工具调用记录只写**实际调用过**的名称与状态。
- 以用户原始选择/操作授权、冻结协议、真实 Run 与项目 STATE/EVENTS 为准。MCP 的 `next_action_hint`、`APPROVED` 字段、私有 receipt 或静态 PASS 都**不是新操作授权或科学验证**。历史案例检索只是索引，科学适用性须核 Task、输入可见性、数据、split、指标与原证据。
- 避免固定轮次复审、全库重读和一次执行多个校准 Prompt。规则/Task/证据未变化就复用核实结果；普通已授权 DEV 可自主连续进行，重要科学变更才更新现有 `RESEARCH_RECORD.md` / `PAPER_BLUEPRINT.md`。

## C10-A｜Agent 状态恢复与自主接续

**触发**：新会话、中断恢复或项目身份不确定；不是每轮都要执行。

**可直接复制的 Prompt**

```text
请按当前 PD-RW-Agent Skill 恢复并继续本科研项目。先核真实项目身份、目录与已许可来源；若 WorkBuddy 的 MCP 已连接且该项目已登记，优先实际调用一次 get_resume_context(project_id, detail_level="compact")，不无故重复调用 get_project_context。MCP 不可用则一次性说明原因，改用合法原始文件。

依据原始用户决定、冻结协议和 Run，区分科研阶段、历史操作状态及下一合法行动；不把旧任务禁止盲目重启误判为整个项目不能继续。未知与冲突只阻断受影响操作，继续其他独立合法工作；不虚构证据、科研结果或授权。

优先直接连续完成已授权的普通 DEV 任务，复用已有结果，不重开已选题、不重跑状态不明的旧实验。简要报告实际恢复证据、关键阻断、所做行动和下一步；没有实际执行则注明 NOT_RUN。
```

## C10-B｜Agent 执行偏差校准

**触发**：出现可观察偏差或重要交付不符；没有实质问题不要重复审计。

**可直接复制的 Prompt**

```text
请用现有 PD-RW-Agent Skill 与 PD-RW 原始规则，针对当前实际任务核查可验证的执行偏差。复用已核项目身份、规则版本、授权和 Run；仅在发现相关证据冲突、误判、遗漏或重复实验时调用对应的 audit_project_state / reconstruct_project_history / verify_run_evidence / audit_scientific_experiment 等可用工具，不执行全量固定审查链。

检查错误科学结论、无信息价值的重复实验及重要变化后 RESEARCH_RECORD/PAPER_BLUEPRINT 是否需要增量更新。发现真实问题则在既有授权内直接修正并继续；没有实质偏差就继续原任务。只报告偏差、原始证据、实际修正及下一合法行动；不新建阶段、重复人工确认或凭工具 PASS 证明科学成立。
```

## C10-C｜Agent 关键门禁检查

**触发**：确实涉及重大作者战略选择或受限操作；不用于常规安全 DEV 调参。

**可直接复制的 Prompt**

```text
请对当前即将执行的具体操作，按 PD-RW 权威规则核真正适用的关键门禁：作者已选的核心 Task/Claim 与战略委托、真实 CPU/GPU/下载权限、SEALED/独立确认隔离，以及涉及付费、外传、绘图、正式写稿或投稿的独立许可。

只以可核验的用户原消息、冻结协议和实际执行环境为依据。STATE 标志、MCP 可见性、预检 PASS 或 Agent 自述均不构成原始授权；本检查本身也不授予许可。已批准范围内的普通安全 DEV 继续自主执行，关键许可不足只暂停受影响操作，保留其他合法工作。简要说明实际门禁结论、证据、限制和下一行动。
```

## C10-D｜Agent 科研价值与历史经验复用（可选）

**触发**：重要负结果、科学主张变化或持续投入但没有新信息；非每次 Pilot 后必做。

**可直接复制的 Prompt**

```text
请依据当前 PD-RW 与真实科研证据评估下一项最有价值的研究行动。优先复用有效 Run、强基线、最近邻文献和已确认结论；需要跨项目经验时，按需用 search_research_memory 找候选，再用原始 Run、review_lesson_applicability / review_evidenced_lesson 或等价证据核验其失败机制、Task、数据、split 与评价前提。索引匹配不等于科学等价，历史失败不是自动 STOP。

比较继续优化、补决定性证据、收窄 Claim、合理转向和结束当前分支的知识增量、成本、关键反证与 JCR Q2+ 投稿潜力。区别技术错误、有效负结果和证据不足；一次负 Pilot 不否定整个项目。推荐一个最有依据的行动并在已有授权范围内继续 DEV；实质更改核心 Task/Claim 或项目整体 STOP 仍由作者决定。只报告关键依据、未知及下一合法行动。
```

## C10-E｜全新科研项目启动

新项目使用 **[C10-E 全新科研项目启动模板](C10-E_全新科研项目启动.md)**。保留方向、A–J 研发目标、贡献、数据、Windows 11 / RTX 4080 16 GB、周期等作者配置。新项目先完成科研机会核查及必要作者选择；真实项目及私有映射建立前，**不得假调用现有项目恢复 MCP**。已有项目使用 C10-A，不重建。

**最简用法**：新项目 E；已有项目恢复 A；观察到偏差 B；即将执行受限操作 C；科学价值发生重大疑问 D。选择一条即可；实际收益与 Token 节省仍需 WorkBuddy 对照验证，不能由提示词文本自证。
