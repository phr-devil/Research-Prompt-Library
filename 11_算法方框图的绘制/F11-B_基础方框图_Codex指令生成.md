# F11-B｜Step 2：把已确认方案转为完整 Codex 绘图指令

> **用户 → ChatGPT → Codex**。第一步已经完成科研结构设计与人工确认；第二步不再要求论文原文、Methods 或代码。**ChatGPT 必须把完整方案写进交付给 Codex 的指令，同时明确使用哪个绘图 Skill。** Codex 只负责实现基础 HTML/SVG。

## 可直接复制的 Prompt

```text
现在进入 F11 第二步。请基于本对话**第一步已经由我确认的最终 Figure Blueprint**，直接生成一份可复制给 Codex 的完整基础绘图指令。

**无需我重新上传论文原文、Methods、算法代码或参考论文。** 请先将已有文字方案转换成足以独立执行的明确绘图规范，而不是让 Codex 重新理解科研方案。ChatGPT 本轮只写 Codex 指令，不亲自绘图。

【指令必须包含的三部分】

1. **绘图 Skill（明确指定，不可仅写“使用适当 Skill”）**
   - 如果我此前指定了绘图 Skill，优先使用该 Skill，并在 Codex 指令中列出名称、已知路径/来源和用途。
   - 未指定时，默认推荐 `svg-figure`（SVG 方框、箭头、文本对齐及布局规范），来源：
     https://github.com/neuromechanist/research-skills/blob/cf52ffe6e518281ec574f2e1b4365c8bdf467d6f/plugins/figures/skills/svg-figure/SKILL.md
   - 说明给 Codex：如果本地已安装且可用，就按需读取该 Skill 中与 SVG 手工绘制有关的部分；如果未安装但可读取上述文档，可将其作为技术参考；都不可访问则直接用原生 HTML/SVG 实现并如实说明。不要假称 Skill 已安装，不要为绘图自动下载安装整个工具链。
   - Skill 只负责矢量绘图、排版与基础验证，不得覆盖我已确认的科学结构，也不得强制添加装饰或复杂功能。

2. **完整、可执行的图形设计方案（必须在 Codex 指令正文中直接讲清楚）**
   - 图号、绘图目标及一句话核心科学创新；
   - 全部必要的主模块与辅助模块：模块名、简要科学作用、应展示的英文标题/必要公式/关键标签，稳定 N-ID；
   - 清晰的布局描述：整体阅读方向、主线顺序、分支和并行关系、上下/左右区域、哪些节点同组、创新重点如何突出；
   - 逐条列出必须绘制的有向连接 E-ID：起点→终点、数据/参数/模型状态/控制/反馈/评价类型、箭头方向与必要文字，尤其注意冻结状态、训练/推理边界及 evaluation-only 输入；
   - 列出关键不变量、禁止连接、不能省略的公式/标签，以及可合并或不画的普通细节；
   - 具体到 Codex 可以仅凭本条指令直接画图。不得仅写“参考第一步方案”“见上文”或只给出没有科学描述的 N/E/F 编号。
   - 方案必须忠实于**已确认的蓝图**，不得新增科学机制或根据 Skill 重新设计内容。

3. **Codex 的实现与验收要求**
   - 使用原生 SVG + 自包含 HTML，几何形状、文字、必要公式及清晰箭头为主；**第二步不使用机器人或装饰 SVG 资产**，视觉增强留到第三步。
   - P0 必须保留，P1 尽量简洁表达，P2 不画；不要将所有算法细节做成方框，不要填满画布。明确主流程，辅助内容弱化，保留舒适留白。普通内容合并不等于删除已确认的关键节点与依赖。
   - 在 SVG 为科学节点和边保留 N-ID/E-ID；输出 `figure_base.html`、同内容的 `figure_base.svg` 及轻量 `figure_structure.json`（节点、边、关键公式/隔离/禁止依赖），使第三步可核对科学结构。
   - 根据已确认方案检查节点和箭头无遗漏、方向正确、无评价泄漏、无文本遮挡；条件允许时预览一次。不要生成 PNG/PDF、复杂框架或大量日志。
   - 科学关系有未解决的实质性矛盾时报告，不让 Codex 猜测。不要重新索取论文正文；如果当前对话确实缺少第一步最终蓝图，只需说明缺少**该蓝图**，而不是请求重新提供论文。

【最终只输出】
一份完整、可直接发送给 Codex 的指令，其中有明确的“使用 Skill”“算法图详细方案”“绘图实现与验收”三个部分。所有已知的具体模块、箭头和布局都应被填好，不能留“请填入方案”之类的占位符。

优先精简文字和执行过程，但不能为了节省 Token 省略绘图所必需的科学关系。
```

## 使用与交接

- **Step 1 由 ChatGPT 完成科研方案**；**Step 2 由同一 ChatGPT 整理完整方案与 Skill，形成 Codex 可独立执行的指令**；无需把论文原文再次交给 Codex。
- Codex 负责基础图和 `figure_structure.json`，保留后续 F11-C 设计增强空间。只有跨对话确实无法检索到最终蓝图时，才需要转交**Step 1 的蓝图文本**，不需要原始论文。
