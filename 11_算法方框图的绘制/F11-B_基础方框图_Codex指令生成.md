# F11-B｜Step 2：基础结构与矢量实现指令

> 用户 → ChatGPT → Codex：将已确认的蓝图转换为独立执行的完整 Codex 指令；本步确保科学表达正确及后续原生可编辑性，不追求最终审美。

## 可直接复制的 Prompt

```text
现在进入 F11 第二步。基于本对话中已由我确认的最终 Figure Blueprint，生成一份可直接交给 Codex 的完整基础绘图指令。ChatGPT 本轮只写指令，不绘图。无需重新上传论文、Methods、算法代码或参考论文；若确实缺少最终蓝图，只指出缺少该蓝图，不要求重复提交原文。

【指令必须包含三部分】

1. 使用 Skill
- 优先使用用户此前指定的绘图 Skill，明确名称、已知路径/来源、用途；未指定时使用 svg-figure（SVG 绘制、文字对齐、布局与基础验证），来源：
  https://github.com/neuromechanist/research-skills/blob/cf52ffe6e518281ec574f2e1b4365c8bdf467d6f/plugins/figures/skills/svg-figure/SKILL.md
- 本地可用时按需读取；未安装但文档可访问时作技术参考；均不可访问时直接用原生 HTML/SVG 并如实说明。不得假称已安装，不自动下载安装整个工具链。Skill 不得覆盖科学蓝图。

2. 针对本图的完整绘图方案
- 直接写清 Figure Profile、图号、图形类型、核心主旨、目标期刊与实际显示尺寸（未知则标暂定）。
- 写明所有必要 N-ID、科学作用、应展示的英文标签、公式、数值，以及 E-ID 对应的真实关系类型、方向（如适用）、标签和依赖；保留已确认 P0 与选定 P1。
- 给出关键 F-ID、单位、统计分母、数据集与证据性质、冻结状态、训练/校准/推理/评价边界、禁止依赖及仍未解决的实质风险（仅适用时）。
- 写清主阅读路径、分区、核心创新、推荐视觉编码及可合并/省略的 P2。按图形类型自主选择机制示意、并列比较、数据图、流程等表达方式。
- 科学语义完整不等于一节点一框、一关系一箭头。允许用共享连接、分组、标签、公式、包含或空间对应表达；有方向的关系须清晰无歧义，不能用视觉合并隐藏关键关系。
- 指令必须自包含，不能只写“参照第一步”、只列 ID 或留下待填模块。严格忠实于已确认蓝图，不让 Codex 重新解读论文或选择研究方案。

3. 绘图实现与验收
- 原生 SVG + 自包含 HTML。用可编辑文字、几何形状、必要公式、连接及真实数据图完成基础图，P0 完整、选定 P1 简洁、P2 不画；有主次、合理留白，不机械堆方框。示意与真实结果须区分。
- 本步不使用机器人或装饰 SVG 资产，不追求最终配色及特效；从开始考虑 Draw.io 原生对象映射：文字、形状、比例条及语义连接可独立编辑，避免复杂滤镜和文字转路径。第三步必须交付原生 .drawio，本步不要求提前生成。
- 保留稳定 N/E/F-ID，允许科学节点与视觉元素多对多映射。生成轻量 figure_structure.json：记录冻结的科学节点、关系（含方向/类型）、公式、数值/分母/单位/证据来源、隔离/禁止依赖及基础视觉映射。将冻结语义与视觉映射区分；第三步不可改写此原文件，视觉变化另记于布局或生成源码。
- 输出 figure_base.html、同内容的 figure_base.svg、figure_structure.json。按需保存共享布局或生成脚本，不强制复杂工程。HTML 内联资源，SVG 独立可用。不要正式导出 PNG/PDF；允许临时预览。
- 集中检查科学信息、方向与隔离、渲染、文字遮挡及越界；工具可用时实际预览一次。对明显问题集中修复，实质科学矛盾报告而非猜测，普通布局/实现自主处理；无法验证的事项如实说明。

【最终只输出】一份可独立发送给 Codex 的指令，含“使用 Skill”“本图详细方案”“绘图实现与验收”三部分，所有具体科学内容已填好。要求 Codex 连续完成，不反复规划或启动额外 Agent，最终仅报告文件路径、关键验证结果与未解决问题。节省 Token，不以删减必要科学关系为代价。
```

## 使用与交接

ChatGPT 转述已经确认的蓝图，Codex 不需要论文原文。F11-B 的三个文件交给 F11-C；如在同一工作区则直接复用。原有科学语义冻结，第三步允许重排视觉编码，不需再次人工确认。
