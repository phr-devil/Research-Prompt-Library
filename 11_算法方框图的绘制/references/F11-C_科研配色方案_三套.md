# F11-C｜科研配色三套方案（已核对来源）

本文件用于 **F11-C 的最终视觉设计阶段**，不修改 F11-A 的科学蓝图、F11-B 的结构基准，也不是新的绘图阶段。基于科研可视化领域的真实配色体系，为**浅色填充的 HTML/SVG 算法框架图**提供可直接使用的填充/描边搭配。

> **来源边界**：以下“原始色值”来自对应科研配色体系；“F11 适配色”由本提示词库专门为论文方框图选定，**不是原作者发布的方框图模板或配色标准**。不应把后者描述为原版科学配色的所有色值。

## 选色规则

- **A｜Paul Tol Pale（默认）**：低饱和、浅填充、留白较多的简洁学术框架图；最接近当前用户喜欢的参考图风格。
- **B｜Okabe–Ito**：分支/机制种类较多、需要相对清晰的功能区分时使用。
- **C｜ColorBrewer Set2**：带 Robot Toast 小插画、希望柔和且更有设计层次时使用。
- 一张图**只选择一个配色方案**，通常从该方案选择 2–3 个功能色。颜色表达语义，但**必须同时用标签、箭头类型或位置表达科学关系**。不要让色彩替代数据/参数/评价依赖的区分。
- 浅色块内使用深文字；边框细而清晰。检查缩小到论文实际栏宽后的阅读效果，并在条件允许时检查灰度表现及色觉差异。配色的科学来源不等于每个自定义适配组合均经过可访问性验证。
- 先确定主视觉焦点、容器形状、布局、留白和内容密度，再挑色，最后考虑 SVG 插图。不要把画布每个区域填满。

## 通用中性色（适用于三套方案）

| 用途 | 色值 |
|---|---|
| 主背景 | `#FFFFFF` |
| 轻分区背景 | `#F7F9FB` |
| 主文字 | `#243447` |
| 次文字 | `#5B6B7C` |
| 主箭头 | `#44576A` |
| 弱化虚线 | `#A5AFBA` |

普通模块使用圆角矩形（参考半径 8–12 px）；阶段分组容器使用较大圆角（12–18 px）。这些尺寸是布局参考值，需随实际 SVG 尺寸缩放。

## Palette A｜Paul Tol Pale：浅色学术风（默认）

**原始依据**：[Paul Tol's Notes — Colour Schemes](https://sronpersonalpages.nl/~pault/)。“Pale”是为**深色文字下的浅背景区域**设计的；原作者也明确提醒这些浅色彼此不够容易区分，不宜直接用作需要强区分的线条/地图类别。

**选用的原始 Pale 填充色：**

| 角色示例 | 原始填充色 | F11 适配描边色 | 说明 |
|---|---|---|---|
| 数据 / 输入 | `#AACCEE` | `#3D6B9D` | 浅蓝 |
| 核心处理 | `#BBDDBB` | `#228833` | 浅绿 |
| 重点机制 | `#EEEEBB` | `#857828` | 浅黄 |
| 可选反馈 | `#EEBBDD` | `#8A518A` | 浅紫，谨慎增加 |

原始 Pale 还含 `#CCEEFF`、`#FFBBCC` 和 `#DDDDDD`，以上仅列适合当前框架图的 4 个常用颜色。**深描边不是 Pale 原始色板**；颜色的科学语义标签也不是 Tol 给定的规定。

推荐：白底、深色文字、主流程最多 2–3 个浅色，必要时利用不同的容器轮廓和线型区分阶段。

## Palette B｜Okabe–Ito：高辨识度技术风

**原始依据**：[Okabe & Ito — Color Universal Design](https://jfly.uni-koeln.de/color/)。原始体系面向更易被不同色觉人群区分的视觉设计；F11-C 的**浅填充为另外调制**，不可声称这些浅填充自动拥有原始色板的全部辨识性能。

| 用途示例 | F11-C 适配填充 | 原始 Okabe–Ito 描边色 |
|---|---|---|
| 数据 / 输入 | `#EAF4FA` | `#0072B2` 蓝 |
| 核心方法 | `#E8F6F1` | `#009E73` 蓝绿 |
| 关键创新 | `#FFF1E7` | `#D55E00` 朱红 |

同一原始色板可选天空蓝 `#56B4E9` 用于少量强调，但不建议与深蓝同时承担需要强辨别的不同模块类别。文字仍使用通用深色，不要把强饱和强调色当小字号文本颜色。

## Palette C｜ColorBrewer Set2：柔和彩色插画风

**原始依据**：[ColorBrewer 2.0 — Set2](https://colorbrewer2.org/?n=4&scheme=Set2&type=qualitative)。Set2 是成熟的**定性类别配色**，而不是专门为算法框架图设计的填充/描边组合。下面的搭配由本库适配。

| 用途示例 | Set2 原始参考色 | F11-C 适配填充 | F11-C 适配描边 |
|---|---|---|---|
| 基础 / 输入 | `#8DA0CB`（蓝紫） | `#EEF1F9` | `#6879A5` |
| 核心方法 | `#66C2A5`（薄荷绿） | `#EAF6F1` | `#368C74` |
| 关键机制 | `#FC8D62`（珊瑚橙） | `#FFF0E8` | `#C86F4F` |
| 可选反馈 | `#E78AC3`（粉） | `#FBEAF5` | `#B86796` |

更适合配合小机器人等语义插图。画面已有彩色插图时应主动减少彩色框体数量，避免互相争夺视觉注意力。不可将 Set2 整套无条件认作完全色觉安全。

## Codex 简短调用方式

在 F11-C 阶段：依据用户明确选择，或默认选 **A / Paul Tol Pale**；读取本文件中对应方案即可，不要同时展开三套代码或检索额外图标。把选定的 **填充、描边、中性色**用于既有 HTML/SVG。记住**圆角、浅底深字、整图留白、主流程突出、科学结构不变**；如引用色板来源，区分科研原始色值与本库适配色。

本文件只提供颜色和应用边界，**不额外生成 SVG/PNG 素材，也不要求改变 F11 已有 56 个 SVG 资产**。
