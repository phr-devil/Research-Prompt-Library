## 可直接复制的 Prompt

```text
请基于 Step 1 已确认的 Figure Blueprint、Step 2 已生成的基础 HTML/SVG，以及我提供的参考图片，为 Codex 写一份**设计增强任务指令**。你只生成 Codex 指令，不直接重画或重新定义算法。

【目标】
将基础方框图升级为一张有版式设计感、视觉层级和统一插图语言的论文方法图。学习参考图的“顶部机制条 / 横向核心流程 / 侧边状态或结果容器 / 底部关键公式或反馈区”等**信息组织方式**，但只呈现本论文实际存在的结构，不能机械套用这些区域，更不能复制参考图的科研内容。

【要求 Codex 依次执行】
1. 先保留并核对基础图中的科学节点、边、方向、类型、关键公式和标签。可以调整尺寸、位置、分区与视觉层级，但科学结构不得变化；只允许因确切逻辑错误而停止并报告，不擅自添加或删除科研节点。
2. 从全图层面设计构图：建立清楚的主视觉动线，利用大小对比、分区容器、统一对齐、留白、颜色语义、标题层级及流畅的箭头路径突出主要创新。不是简单换配色/加图标，也不做花哨海报。非科学内容的装饰容器与标题不得被误读为算法步骤。
3. 使用克制的平面学术风格：白底、柔和低饱和色、少量暖色强调、适中的圆角和细描边、字体/公式易读。对齐和空间节奏比装饰更重要。重点机制允许更大视觉权重，不要求所有框相同大小。
4. 按需使用 F11 SVG 资产：先查 manifest.json 的 style/concepts，再只读取实际选中的 SVG。Robot Toast（16 姿态）可表示具有角色语义的核心功能；通用小图标从 Lucide、Tabler、Phosphor Duotone 三套中优先选**一套**；OpenMoji 4 项只作少量强调并遵守 CC BY-SA 4.0 署名/改编要求。没有合适素材就省略，不能为了配插图新增模块。保留源矢量的比例、可编辑性，处理 SVG ID 冲突，不用在线资源或位图截图。
5. 不以固定图标数量为目标。优先“主视觉区 + 少数高价值插图 + 适度公式/辅助示意”，确保论文缩小排版后依然清晰。视觉优化可以重排布局，但不改写科学内容。
6. 对照 Step 2 的结构基准检查节点/边/公式未漂移；再检查文字、遮挡、箭头、分区边界、图标尺寸与资源许可。可用浏览器时预览整图及缩小后的可读性；不能验证时如实说明。

【输出】
在现有代码基础上修改（除非基础结构无法支持所需布局），交付最终自包含 HTML、独立 SVG 及必要的可复用源码。不强制导出 PNG/PDF。只汇报产物、设计层面关键变化、结构一致性检查和未解决问题，不重复大量源码或解释。

请只输出给 Codex 的精简、可执行指令。目标是**有设计感的科研图**，而不是“装饰过的方框图”。
```
