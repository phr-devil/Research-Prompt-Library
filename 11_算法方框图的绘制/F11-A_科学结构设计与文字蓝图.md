# F11-A｜Step 1：科学蓝图与视觉构思

> 用户 → ChatGPT：根据已有科研材料直接设计文字蓝图；不绘图、不写代码。仅在本步进行一次科学确认。

## 可直接复制的 Prompt

```text
请基于当前论文/算法、Methods、代码及科研记录，为指定 Fig.X 或 Graphical Abstract 设计一份可独立交给 Codex 的 Figure Blueprint。优先复用已有证据，不重复读取无关材料。本阶段不绘图、不写代码。

1. 科学主旨与图形类型：用一句话明确本图的核心贡献和读者应理解的结论。按实际目标选择 Graphical Abstract、Algorithm Architecture、Mechanism Diagram、Experimental Workflow、Conceptual Framework 或 Results Figure，可组合形式，不默认方框图。明确目标期刊、最终图宽/显示尺寸；未知时标为合理的暂定设计值，不编造期刊规范。按图形类型突出发现、方法机制、物理因果、实验逻辑或真实定量证据。

2. 信息筛选：P0 为不可省略的核心科学语义（必要输入、机制、输出、依赖、隔离、关键证据）；P1 为增强解释力的公式、分支、定量结果和辅助机制，按需展示；P2 为普通预处理、实现参数和重复信息，默认合并或省略。区分科学概念与视觉对象：节点可由标签、公式、插画、状态标记、数据图或组合容器表达，不要求一节点一方框。优先展示有证据的创新及优势，不把理论上限、假设、探索性结果或阴性结果说成已实现的性能提升。

3. 科学关系：根据真实方法识别数据、参数、模型状态、控制、反馈、评价及物理因果关系，区分时序、并行、分类、包含、对应与相关性。仅对确有方向的关系指定方向；禁止将分类或相关性画成时序/因果，不凭参考图虚构循环、模块或箭头。若涉及学习算法，核对训练/校准/推理/评价的信息边界、冻结状态和数据可见范围，禁止评价真值提前进入部署模型。不存在的机制不强行添加。

4. 证据与不确定性：关键节点、关系、公式、定量结果（含单位、分母、适用数据集及证据状态）可追溯至 Methods、代码或研究记录，简短注明来源。影响科学正确性的缺失信息标“待核实”，不要猜测；普通视觉细节不必逐一审计。真实统计图不得捏造数据；示意图须与实证结果明确区别。

5. 视觉构思：先确定科学叙事、视觉焦点、信息层级和主阅读路径，再选择构图。可采用横向、中心辐射、并行对比、剖面、层级、状态分解或方法与定量图组合等形式。明确哪些依赖必须有箭头，哪些可用分组/包含/对应表达；哪些定量结果能代替文字。参考图只提供视觉组织、构图、留白和风格，不提供科学证据。不机械限制区域数、方框数或方向。视觉方案是建议，不冻结坐标、颜色、容器及最终构图，为第三步保留设计自由度。

【输出唯一精简且完整的 Figure Blueprint】
- Figure Profile：图号、图形类型、目标期刊、实际图宽/显示尺寸（未知则标暂定）。
- Message：一句话主旨及核心创新。
- Nodes：N-ID｜科学概念/模块｜作用与阶段｜P0/P1｜必要来源。
- Edges / Relations：E-ID｜相关节点｜关系类型、方向（如适用）｜必要标签/来源。
- Invariants：F-ID｜不可改变的公式、符号、数值、单位、分母、证据性质、冻结/隔离及禁止依赖；没有则不虚构。
- Visual Encoding：关键内容推荐用独立形状、组合区域、标签、公式、机制示意或真实数据图表达。
- Layout：主阅读路径、功能区域、视觉焦点、主次比例与省略内容。
- Risks：仅列影响科研正确性的未决实质问题。

Nodes、Edges / Relations、Invariants（含已选定展示的 P1）是后两步唯一科学语义基准；Visual Encoding 与 Layout 可继续优化。请让我确认一次科学蓝图；确认后不再重新选择科研方案。发现实质科学矛盾时仅对相关部分报告并请求必要的重新确认，不为普通视觉问题增加审批。
```

## 使用与交接

同一对话沿用用户确认的最终蓝图；跨对话只需交接蓝图，无须重贴论文。F11-B 保存稳定 N/E/F 语义；F11-C 可以改变视觉映射，不得改写科学含义。
