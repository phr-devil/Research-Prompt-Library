# F11-A｜Step 1：科学结构设计与文字蓝图

> **用户 → ChatGPT**：提供论文方法、核心贡献与参考图。ChatGPT **直接设计文字蓝图**，不调用 Codex、不绘制 HTML/SVG。只在蓝图完成后进行一次科学确认。

## 可直接复制的 Prompt

```text
请根据当前论文/算法材料，为 Fig.X 设计可独立交给 Codex 的 Figure Blueprint（文字版）。参考图只用于借鉴信息层级、构图和留白，不照搬其模块、公式或因果关系。本阶段不绘图、不写代码。

1. 科学主旨：用一句话明确本图要解释的核心贡献。按重要性筛选 P0（必须保留的输入、机制、输出、依赖及隔离）、P1（关键公式/分支/反馈，按需展示）、P2（普通预处理、实现参数和重复细节，默认合并或省略）。不要逐行复述代码，也不机械限制方框数量。
2. 科学关系：按实际方法区别数据/参数/模型状态/控制/反馈/评价关系，识别并行与时序、训练/校准/推理/评价可使用的信息。禁止凭参考图造出新循环、新模块或让评价真值提前进入模型；仅在材料有证据时才画这些关系。
3. 证据和不确定性：关键节点、边及公式应能追溯到提供的 Methods、代码或研究记录（简短指出对应小节/来源即可）。确实缺失且影响科学正确性的关系标“待核实”，不要猜测；普通细节无需逐一审计。
4. 版式构想：根据科学结构推荐一种主要布局，并指出视觉焦点。可借鉴横向主线、侧边状态区、顶部机制条、底部评分/反馈区，但只在算法真实存在时采用；为后续设计增强留出空间。

【输出一个唯一的精简 Figure Blueprint，不重复多种版本】
- Message：本图的一句话主旨。
- Nodes：N1…｜模块名｜科学作用/所属阶段｜必要时标注来源。
- Edges：E1…｜起点→终点｜关系类型（data/parameter/control/feedback/evaluation）｜必要标签/来源。并行不伪装成前后因果。
- Invariants：F1…等必须准确保留的公式/符号，以及冻结状态、数据可见范围、禁止出现的依赖；不存在时写“无特殊约束”，不虚构。
- Layout：主要视觉动线、可分组区域与核心视觉重点；合并/省略的普通细节。
- Risks：仅列仍未解决且影响画图准确性的原则性问题（如有）。

以上 Nodes、Edges、Invariants 共同构成后两步唯一的科学结构基准。请让我确认科学蓝图一次；确认后不要在绘图阶段重新选择科研方案。
```

## 使用与交接

同一对话直接沿用**用户确认的最终蓝图**；跨对话只需带上这份蓝图，无须重贴整篇论文。Blueprint 中的 N/E/F 标识将被 F11-B 转成轻量结构基准，F11-C 不能擅自改写其科学语义。
