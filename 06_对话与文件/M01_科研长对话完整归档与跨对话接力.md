# M01 · 科研长对话完整归档与跨对话接力

> **用途**：生成适合开新聊天的高保真接力 Markdown，保留错误、决策、文件和数据  
> **版本**：v1.2（2026-10-21，重点任务重构）  
> **来源类型**：方法融合自摘要 Prompt；科研接力结构为针对日常工作新编；以下正文为重新组织的原创适配版，不是 GitHub 原文的逐字复制。

## 使用前填写

可访问对话及文件范围、当前日期/版本、接力目的、详略（快速接力/完整档案）、禁止公开的信息

## 可直接复制的 Prompt

```text
你是科研项目的事实归档员。请将【当前真正可访问的聊天、实验日志、论文材料和文件】整理为新对话可用的 Markdown。项目【】；归档截至【日期/版本】；输出模式：【快速接力 / 完整档案 / 两者兼有】。不要把没有访问到的前文、GitHub、附件或本地路径当作已检查。

首先明确：已读的消息/文件及其日期和版本；未读、截断、无法验证的部分。保留能支持后续决策的信息，不因追求短小而省略失败经验。

输出层级：
A｜快速接力（适合粘贴到新对话，优先不超过约 800 中文字）：
- 研究目标及当前状态；核心已验证结论与关键数值（单位/样本量/区间）；重要失败或已否定路线；当前阻碍；紧接着要做的 1–3 个任务；明确不能违反的限制。
- 最后给一段可直接粘贴给新 AI 的启动指令，禁止它把待做计划当成既有成果。

B｜完整档案（在选择完整档案或两者兼有时输出）：
1. 研究范围、术语、算法/设备/数据集和参数；
2. 数据划分、统计协议、文件路径、hash、随机种子和版本（仅限确实看到的字段）；
3. 实际运行与结果：真实/模拟/拟执行分别列出，含误差、CI、基线和负结果；
4. 决策与修复时间线：方案、证据、错误、解决办法、为何停止或替换；
5. 待办任务、负责人（如已知）、优先级、GO/HOLD/STOP 门槛；
6. 尚缺来源与新对话需要再次读取的文件。

每项重要结论采用「陈述｜状态〔已验证/初步/待核实/已推翻〕｜证据位置〔消息日期/日志/文件章节〕」的形式；没有可定位来源就标「来源未保留」，不要编造引用。出现矛盾时并列不同版本及证据，不因为最后一条消息较新就默认正确。

最后做遗漏自检：失败实验、未完成工作、负结果、文件版本和不再采用的路径是否仍可恢复。若用于公开分享，排除个人隐私、账号凭据及不需要的敏感材料；不把新对话的记忆能力当作已经保存了完整档案。
```
