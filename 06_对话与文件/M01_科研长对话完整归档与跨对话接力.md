# M01 · 科研长对话完整归档与跨对话接力

> **用途**：生成适合开新聊天的高保真接力 Markdown，保留错误、决策、文件和数据  
> **版本**：v1.0（2026-10-21）  
> **来源类型**：方法融合自摘要 Prompt；科研接力结构为针对日常工作新编；以下正文为重新组织的原创适配版，不是 GitHub 原文的逐字复制。

## 使用前填写

聊天全文、附件/路径、起止时间、接力目标、归档详略

## 可直接复制的 Prompt

```text
请将【当前可访问的整段对话及已提供文件】归档为一份高保真科研接力文档，给另一个完全不了解项目的 AI 使用。你只能总结确实可访问的内容；如果缺少前文或附件，不得声称已经阅读。

采用以下稳定结构：
01 项目目标、研究范围与当前版本；02 已确认的事实和术语；03 数据集/样本/设备与详细参数；04 算法、公式或研究方法；05 已运行实验及结果（保留单位、样本量、置信区间、随机种子、文件 hash）；06 已解决错误、修复原因与验证；07 曾尝试且证据表明不适合的方向；08 当前待解决问题和阻塞；09 文件路径/版本/时间、关键命令；10 下一步优先级任务与 GO/HOLD/STOP 门槛；11 新对话启动提示词。

每条关键结论标记『已验证 / 初步发现 / 待核实 / 曾被推翻』；冲突结论给出先后时间和证据，不机械以最后发言代替验证。尽量保留决定成败的细节，不保留无价值的寒暄和重复。

最后执行“遗漏审计”：查看是否漏掉重要失败案例、负结果、未完成任务、硬性约束以及文件版本。文档必须自洽，禁止将计划写为已经完成。若对话太长而无法完整访问，列出未覆盖范围与待提供材料。
```

## 使用提醒

- 需要搜索最新规则、论文、金额和截止日期时，应启用实际检索并核查原始来源。
- 涉及文件、实验结果或既往聊天时，只能依据模型真正可读取的材料作判断。
- 请勿把生成的科研主张、参考文献或政策条件直接当作已验证事实。
